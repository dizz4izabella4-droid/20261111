# 動く素体（body-motion）

> **分離済み（2026-11-26）**：形づくりは [スペアボディ（spare-body/）](../spare-body/)、動きは [傀儡（kugutsu/）](../kugutsu/) に分けました。このフォルダは分ける前の元として残しています。

スライダーで形を作る全身の素体に、モーションキャプチャー（作品「モーション」の JSON）を取り込んで動かすためのブラウザアプリ。

- 体：胴と胸は「写真分析成形」（photo-tex、凍結）の素体を引き継ぎ、腕・脚は丸い筒、頭・手・足は仮の箱。
- スライダーは 大項目 → 中項目 → 小項目 の段階で整理。
- 骨格（17本）を最初から入れてあり、各部位は骨に結びつけてある（スキンメッシュ）。

## 段階

1. 体を作る（スライダー・骨格・GLB 書き出し）— **済み（2026-11-26）**、[reports/M1.md](reports/M1.md)
2. 「モーション」の JSON（`dizz-mocap-v1`）を読み込んで動かす（再生・一時停止・コマ送り）— **済み（2026-11-26）**、[reports/M2.md](reports/M2.md)
3. 指（「指モーション」）の組み込み、顔・手足のつくり込み、骨格と動きつきの GLB 書き出し
