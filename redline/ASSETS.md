# REDLINE — 素材導入・用途ガイド

## 素材パッケージ
`REDLINE_assets_v01.zip`（元の独立PNG72点＋素材一覧）の展開先は `redline/assets/`。

```
redline/
  PLAN.md
  CLAUDE_HANDOFF.md
  ASSETS.md
  assets/
    README_素材一覧.md
    board/            # 2
    evidence/         # 21
    photo_prints/     # 17
    maps/             # 5
    papers/           # 11
    desk/             # 9
    props/            # 7
```

## 表示レイヤー
1. ボードのベース: `board/whiteboard_frame_blank.png`
2. 地図・写真・紙類: `maps/` `evidence/` `photo_prints/` `papers/`
3. ピン: `props/red_pushpin.png` など（画面座標にリンク）
4. 赤い紐: **実装側で動的に描画**（素材の固定糸画像を正解接続に使わない）
5. 下部のデスク: `board/desk_area_reference.png` と `desk/` の小物

## 注意点
- 全部フォトリアル素材を基本とし、完成画面の背景絵として街並みを使わない。
- 写真の一部はかなり小さい。拡大時の鮮明さを期待しない。
- 合成画像から切り出した素材の中には暗い背景が残る可能性がある。PNGでも**透明とは限らない**。特に `evidence/` と `maps/` は矩形の写真として使う。
- 日時や文字・地図を含む画像はAI生成であり、**内容の正確性は保証されない**。時刻や論理上の決定的な特徴は確実に整合させる。
- 第1・第3・第5問の条件を現素材だけで満たすとは限らない。観察パズルとして成立するまで写真を検証／再制作する。
- 素材は「候補」であって、すべての採用を強制しない。不要な装飾・UIを増やさない。

## ステージ別素材の必要性
- Stage 01: 写真3、地図/地点3。時計塔・アーチ・線路・運河の一致が必要。
- Stage 02: 監視写真5。日付・時刻を正確な別レイヤーで表示。
- Stage 03: 写真4、地点4。石造アーチ/鉄橋と街灯の点灯消灯を区別。
- Stage 04: 道路地図1。通行可能な7道路の組み合わせを正確に表示。
- Stage 05: 写真5、地点5。格子柵/丸窓/石階段/給水塔/煙突を論理的に一致させる。

## 導入確認
`redline/assets/` 内に72個のPNGが存在するか確認。足りなければ素材ZIPをアップロード・展開し、実ファイルのパスを参照して作業すること。
