# 未解決殺人・証拠品不足：開発管理用

**すべて架空。** この資料をプレイヤー向けの画面へ表示しない。

## 追加範囲
- M-08 鷺浜補給所殺人事件（1997-09-24）：4冊・20ページ
- M-09 城ヶ丘植物標本館殺人事件（1998-06-17）：4冊・20ページ

合計8冊・40ページ。前の7事件・115ページと事故棚42件は変更しない。

## M-08 証拠の欠落
- **確認できること**：伊奈秀樹は19:55に青い書類袋を携えて入所、20:12に電話、21:48に死亡している状態で発見。夜間に高波と停電があった。資材室には海水が流入した。
- **不明なこと**：書類袋が流されたか誰かが運んだか、袋の内容、測深棒が事件当日あったか、誰が加害したか。
- **誤誘導**：『消えた袋を持っていた者が犯人』『測深棒が1本少ない＝凶器』はいずれも未確認前提からの飛躍。
- **仮説の区別に欠ける物証**：袋の現物、内容物、比較可能な足跡、当夜の測深棒の在庫記録。

## M-09 証拠の欠落
- **確認できること**：杉崎澪子は収蔵室で殺害されたとみられる。C-17の台帳と寄託控えに採集地の食い違いがある。採集票原本と標本本体は未回収。緑紐細片2点は採取後、個体識別しないまま同じ封筒に収容された。
- **不明なこと**：C-17の実際の採集地、標本の移動時期、細片の元の採取位置と現物の対応、犯人。
- **誤誘導**：『紐の色が同じ＝特定職員が現場を移動』『空箱がある＝殺害時の盗難』は成立しない。
- **仮説の区別に欠ける物証**：標本、採集票原本、採取位置を復元できる個別封印資料、犯人の直接目撃。

## 重要な制作方針
**どちらの事件にも制作上の確定犯人を設定していない。** 不足している物証を、文章の読み込みだけで都合よく再現することはできない。プレイヤーは複数の説明を比較できるが、犯人を論理的に一意に定められない。その未決性そのものを事件の性格とする。

他の架空事件や事故資料へ不必要な接続を作らない。
