# 外注スタッフ表（ツール担当）

| スタッフ名 | 対応ツール | 役割 | 制約 |
| --- | --- | --- | --- |
| イザベラ | ChatGPT Work | 外注作業、素材調達・制作の支援、資料整理 | 基本設計・主実装は行わず、Claudeの方針に従う |
| ディズ | Codex | デバッグ、不具合の調査と修正 | 基本設計や新規実装の主担当にはしない |

## 制作体制
- Claudeが基本設計・主実装・制作指揮を担当する。
- アストリッド（ChatGPT）はスクリーンショットの分析、技術・ツール調査、素材制作、Claudeへの引き継ぎを担当し、コーディングしない。
- イザベラはChatGPT Workを用いた外注作業を支援する。
- ディズはCodexを用いてデバッグを担当する。
- 既存のスタッフ表の元ファイルは本リポジトリで確認できなかったため、このファイルを追記として作成。元のスタッフ表が見つかれば統合する。
