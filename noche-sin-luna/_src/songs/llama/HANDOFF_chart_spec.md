このドキュメントは、**別のAIまたは実装者がそのまま譜面実装に移れるように**書かれた技術仕様書です。

| 項目 | 値 | 根拠 |

**実装上の注意（重要）**
小節頭の時刻は**固定BPMの数式で近似しないこと**。実測では `t(bar) ≈ 1.858 + 1.5702×(bar−1)` だが、終盤で最大 **約 370 ms のズレ**が出る（テンポがわずかに揺れる）。
→ **`bars.csv` の `t0_sec` と `beatgrid.csv` の `time_sec` を正とする**こと。数式はフォールバックのみ。

- 最初の小節頭：**1.858 s**（0〜1.86 s はギター単独のイントロ＝アップビート扱い）
- 最終小節（bar 74）頭：**117.05 s**
- **118.0 s 以降は無音**（テール 3.5 s）。譜面は **118.0 s で打ち切る**こと。

## 3. 3レーン設計の考え方

マリアッチの実際の音響を帯域で分離し（HPSS＋帯域エネルギー）、3レーンに割り当てた。

| レーン | 対応する実音 | 周波数帯 | 判定の性格 |
|---|---|---|---|
| **GOLPE_BAJO**（低） | ギタロン／ギター胴の低い「ドン」 | 60–220 Hz | 4分・2拍目系。**常に踏める土台** |
| **PALMAS**（クラップ） | ※音源には**存在しない**。設計上の追加レイヤー | 3–9 kHz | 裏拍担当。**音源のハイハット/ビューエラに擬態**させた |
| **GOLPE_ALTO**（高） | ギター表板ゴルペ／ビハウエラの高い「パン」 | 2–9 kHz | シンコペ用。譜面の難所はここ |

> **重要（引き継ぎ時の注意）**：実音としての **パルマス（手拍子）はこの録音には入っていない**（AI解析・帯域解析の双方で確認）。
> ご依頼の「パルマスを入れる」は“**譜面レイヤーとして追加する**”と解釈し、既存の高域パーカッション（ビウエラの刻み）に乗る位置へ配置した。実演奏に合わせたい場合は、PALMASレーンを「Vihuela strum（高）／GOLPE_ALTO」に統合し、2レーン構成に落とすのが安全。

## 3-1. 拍位置の記法
1小節 = pulse 0,1,2,3（= 4分音符）。`0.5 / 1.5 / 2.5 / 3.5` は8分裏、`3.75` は16分裏。

```
bar: |0    .    1    .    2    .    3    .|
      B    A    C    A    B    A    C    A     ← T4系（間奏/サビ2）
      ↑pulse0    ↑pulse1    ↑pulse2    ↑pulse3
```

## 4. セクション別ノーツ仕様（そのまま実装可能）

各ティアの定義（pulse位置 → レーン）：

| ティア | 使用セクション | 内容 |
|---|---|---|
| **T1**（易） | INTRO, VERSE_1 | `0:B`, `2:A` — 1小節2個。2拍目と4拍目だけ |
| **T2**（中） | PRE_CHORUS_1, VERSE_2 | `0:B`, `1:C`, `2:A`, `3:C` — 4個。表裏交互 |
| **T3**（中高） | CHORUS_1 | `0:B`, `1:C`, `2:A`, `2.5:B`, `3:C` — サビ頭の16分シンコペ |
| **T4**（高） | BRIDGE_INSTR, CHORUS_2 | `0:B, 0.5:A, 1:C, 1.5:A, 2:B, 2.5:A, 3:C, 3.5:A` — 8個。8分刻み＋ゴルペ |
| **T5**（最高） | BUILD | T4 に `0:B+C` と `3:C+B` を重ねる（同時押し2箇所）。**全体の山** |
| **T6**（終止） | OUTRO_TAG | `0:B+C`, `1:C`, `2:A`, `3:C` — 鳴りを聴かせる |

**動的な上乗せルール（実測値に連動）**
1. `lo_rel > 0.85`（低域が強い小節）→ pulse2 に **B を追加**（= ギタロンのアクセント）
2. `hi_rel > 0.88`（高域が強い小節）→ pulse1.5 に **A を追加**
3. `bar % 4 == 0` かつ T2–T5 → pulse3.5 に **A を追加**（フレーズ終わりの食い）
4. `bar % 8 == 0` かつ T3–T5 → pulse3.75 に **A**（16分フィル）
5. 静かな小節 → 全削除し pulse0 のみ（サビ/間奏系は **C**、それ以外は **B**）

**固定ランドマークノーツ**
- 2.00 s … B（アンサンブル入りのダウンビート）
- 115.50 s … B、116.29 s … A（終止形 Ta-ta-ta-TUM の頭）
- 117.05 s … A（最終ヒット、velocity 3）

## 7. 既知の限界・未確認事項（正直な申告）

1. **テンポが完全固定ではない**：終盤で最大 ~370 ms のドリフト。固定BPM実装だと後の方でズレる → 実測タイムを使う。
2. **セクション境界は「音響特徴＋聴取」の合成**：bar 単位に丸めてあるため、実際の歌い出しと数10 ms ずれる可能性あり。
3. **PALMAS は創作レイヤー**：実音ではない（上記3参照）。
4. **GOLPE_ALTO の「実音かどうか」**：2–9 kHz の打撃はギター表板ゴルペとビウエラ刻みが混在しており、**分離まではしていない**。厳密に分けたい場合は追加で帯域フィルタ設計が必要。
5. 元音源の著作権は権利者に帰属。譜面データは私的利用・実装検証の範囲で。

## 8. 引き継ぎ手順（次のAIへ）

1. `bars.csv` を読み、`t0_sec` を小節頭テーブルとして採用
2. `chart_notes.csv` をそのままノーツ配列に流し込む（列：`id,time_sec,lane,bar,pulse,section,tag,velocity`）
3. `tag` 列で追加調整：`break`（間）／`fill`（装飾）／`fill16`（フィル）／`final_hit`（終止）
4. 難所5小節（27/34/38/74/28）だけ手作業でリズムを差し替え
5. 118.0 s でフェードアウト、判定は上記6の値から開始
6. 実機で聴感チェック → `offset_sec` を ±30 ms の範囲で微調整
