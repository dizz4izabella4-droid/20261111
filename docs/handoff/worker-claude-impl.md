## 最初にやること
1. 担当作品を、ユーザーまたはリーダーに確認する（言われていれば不要）。
2. `git clone https://github.com/dizz4izabella4-droid/20261111` または `git pull`。`git log` で最近の変更を見る。
3. リポジトリ直下の `HANDOFF.md` のうち、担当作品の章だけ読む（全部は読まない）。古い記述があるので、実際のソースを優先する。

## 守ること
- 応答は**日本語**。正確さを最優先。変更したら、ブラウザ（Playwright + Chromium）で実際に動かして確認してから報告する。実機・耳で確認できていないことは「未確認」と書く。
- **担当作品のフォルダだけ直す**。トップの `index.html`（`APPS`）や `lab/index.html` は、自分の作品の1件だけ。`HANDOFF.md` は**直さない**（リーダーが管理）。
- **main に直接 push してよい**（確認不要）。作業前と push 直前に `git pull --rebase origin main`。`--force` は使わない。コミットは小さく、メッセージは「作品名: 何をしたか」。仕様を変えたときは理由を1行足す。
- **直す場所に注意**：コウモリ・GLASS BREAKER は**アーティファクトが正本**で、リポジトリは写し。ビルド方式の作品（イカロス `icarus/_src/`、Noche sin Luna `noche-sin-luna/_src/`、iz2611 `iz2611/_engine/` と `data/`）は、**ソースを直してビルドする**（ビルド結果の `index.html` を直接直さない）。暗算輪廻は `anzan-tensei/index.html` を直接直す。
- 全作品共通：①iOSの拡大を無効 ②全画面を選べる ③縦横を選べる（`shared/game-base.js`、新作は `tools/apply_game_base.py` の `TARGETS` に登録）。各作品からトップへ戻るリンクは付けない（ブラウザの「戻る」は塞がない）。音を使うなら `<head>` に `navigator.audioSession.type='ambient'`。**画面の表示は基本英語**で、説明がなくても遊べる作りにする（説明文は基本出さない。出すなら最小限の英語）。**実務アプリ（電卓ドリルなど）は日本語**。日本語を出すときは標準の日本語フォントのみ、装飾的なフォントは使わない。既存の日本語UIの作品（暗算輪廻を含む）は、指示があるまで変えない。
- 既存作品に直結する名称・旋律・キャラ名は使わない。ユーザーがカットした要素を黙って復活させない。
- 仕様に迷ったとき、方針を変えるときは、自分で決めず**リーダーかユーザーに聞く**。
