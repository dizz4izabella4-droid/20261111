# REDLINE — 企画・パズル設計書

## 1. コンセプト（確定）

**事件捜査ゲームに見せかけた、赤い紐の接続ロジックパズル。**

プレイヤーは捜査資料が貼られたホワイトボードでピン同士を赤い紐で結ぶ。事件の物語を読み解くことではなく、写真や地図の規則性・対応関係・条件から正しい接続を導くことが中心。最初の「糸口」を見つけると、その接続を起点に残りが連鎖的に確定していく快感を重視。

## 2. 画面構成（確定）

- 画面上部の大部分（目安約80%）: 室内の**ホワイトボード**。写真、地図、資料、ピンを配置する。
- 画面下部（目安約20%）: **書類の積まれたデスク**。初期版では主に背景演出。
- 赤い紐はピンの位置に応じて動的に描画する。線の見た目自体は解答データにしない。
- 操作説明の文章や派手なUIをむやみに増やさず、資料・配置・動きで伝える。
- 割合はレイアウトの目安であり、確定ピクセル値ではない。

## 3. 初期版の操作とルール（確定方針）

- プレイヤーの基本操作は **2本のピンの接続／既存接続の解除**。
- 各ステージの正しい接続集合が完成するとクリア。
- 誤接続は解除できる。試行錯誤を許容する。
- 判定では接続の順番や線の交差ではなく、**無向のピン組み合わせの集合**を照合する（ステージ2・4の経路でも接続集合を比較する）。
- 必要な接続がすべて揃い、不要な接続がないことをクリア条件とする。
- 序盤は写真・地図の**観察**中心、中盤以降に**消去法・時間・経路など論理条件**を段階的に導入。
- 複雑な道具操作、証拠移動、文字入力は初期ロットでは扱わない。

### 写真と地点の対応規則（2026-11-18 追記）

写真と地点を対応づける問題（STAGE 01・03・05）では、**「写真に写る特徴 ⊆ 地点の特徴」**（写真に写る特徴が、その地点の特徴にすべて含まれる）を成立条件とする。完全一致ではない（例：STAGE 01 の写真B［石造アーチ］は、地点2［石造アーチ、線路］と完全一致しないが対応する）。一覧に書いた各問の解答の一意性は、この規則で検算している。

## 4. 初期5問（問題案。各問の詳細な画像制作・プレイテストは未実施）

5問とも、**他の条件を知らなくても最初の一本を論理的に見つけられる糸口**を用意する。以下の記号・一覧は制作側の管理情報であり、ゲーム画面内に表として表示する指示ではない。

**素材の共通制約（2026-11-18 追記）:** 各写真には、下の「写真に写る特徴」に書いた特徴だけを写す。**書いていない特徴は、正解地点にある特徴でも写さない**（糸口と推論の連鎖が変わり、解答の一意性が崩れるため）。各問の「写してはいけないもの」を、そのステージの末尾に書く。

### STAGE 01 — 時計塔の影（観察／3本）

**画面:** 現場写真A・B・Cと地図上の地点1・2・3。各写真を対応地点に1対1で結ぶ。

地点の特徴:
- 1: 時計塔、石造アーチ
- 2: 石造アーチ、路面電車の線路
- 3: 路面電車の線路、運河

写真に写る特徴:
- A: 時計塔
- B: 石造アーチ
- C: 線路

**糸口:** 時計塔があるのは地点1だけ。A–1を結ぶと、B–2、C–3が連鎖して確定。  
**正解:** `A-1, B-2, C-3`。  
**写してはいけないもの:** A＝アーチ・線路・運河／B＝時計塔・線路・運河／C＝時計塔・アーチ・運河。

### STAGE 02 — 午前零時の逃走（時刻順／4本）

**画面:** 5枚の監視カメラ写真。時間順に一本の経路を作る。撮影日時（**日付も**）が視認できる必要がある。

- A: 4/12 23:58、駐車場出口
- B: 4/13 00:14、港湾倉庫
- C: 4/13 00:03、橋
- D: 4/13 00:11、駅
- E: 4/13 00:07、大通り

**日時の表示（確定方針）:** 日付・時刻は、写真の画像内に生成させず、**コードで描く別レイヤーの文字**として各写真に重ねる（AI生成画像の文字は不正確なため。`ASSETS.md` 参照）。

**糸口:** 日付をまたいでおり、23:58が00:03より先。  
**正解の順路:** `A → C → E → D → B`。  
**正解の接続集合:** `A-C, C-E, E-D, D-B`。  
**写してはいけないもの:** 画像内の時刻・日付が読める文字（時計、看板、画面表示など）。判定の根拠は別レイヤーの日時だけにする。

### STAGE 03 — 停電区域（2条件＋消去法／4本）

**画面:** 4枚の写真A・B・C・Dと地図上4地点。1対1で結ぶ。

| 地点 | 建物 | 街灯 |
| --- | --- | --- |
| 1 | 石造アーチ | 点灯 |
| 2 | 石造アーチ | 消灯 |
| 3 | 鉄橋 | 消灯 |
| 4 | 鉄橋 | 点灯 |

写真の特徴:
- A: 石造アーチ
- B: 消灯した街灯
- C: 鉄橋
- D: 石造アーチと点灯した街灯

**糸口:** Dは両条件が一致する地点1のみ。残りはA–2、B–3、C–4と確定。  
**正解:** `D-1, A-2, B-3, C-4`。  
**写してはいけないもの:** A＝街灯（点灯・消灯とも）・鉄橋／B＝石造アーチ・鉄橋（街灯だけを近景で写す）／C＝街灯（点灯・消灯とも）・石造アーチ。Aに街灯が写ると、A–2が先に決まって問題が変わる。

### STAGE 04 — 封鎖された街路（経路の消去法／5本）

> **【廃止 2026-11-18】監督判断: 経路型（STAGE 04系）のギミックは今後使わない。** 試遊版から除外済み（旧STAGE 05は試遊版ではCASE 04）。以下は経緯の記録として残す。「全地点を通る」条件の伝え方の検討も不要になった。

**画面:** 地図に出発S、到着T、途中A・B・C・Dを示す。通行可能な道路だけに沿って、**すべての地点を1回ずつ通る**経路を完成する。ピンへの接続操作は共通のまま。

**通行可能な無向道路（全7本）:** `S-A, S-B, A-B, A-C, B-D, C-D, D-T`。

**糸口:** Tに入れるのはDのみ。Cに接続できるのはAとDのみ。終端付近の条件から経路を遡る。  
**唯一の正解順路:** `S → B → A → C → D → T`。  
**正解の接続集合:** `S-B, B-A, A-C, C-D, D-T`。

**解が1通りになる条件（2026-11-18 追記・検算済み）:** 「**S から T まで、A・B・C・D をすべて1回ずつ通る**」ことが条件に含まれて初めて、正解が上の1本に決まる。この条件がないと、`S-B-D-T`、`S-A-B-D-T`、`S-A-C-D-T` も道路上の経路として成立する。したがって、**この条件をプレイヤーが説明文なしで知れる仕組みが必須**（下の制作注意）。

**制作注意:** 画面の道路線は「接続可能」を表す情報であり、プレイヤーが結んだ赤い紐とは別に描画する。道路網は画像に生成させず、**コードで描く（全7本のみ。他の道路を描かない）**。道路網以外を結べないルールの提示方法と、「全地点を通る」条件の伝え方（候補：紐が通ったピンが赤く点灯し、全ピンの点灯がクリアの合図になる）は未決定。  
**写してはいけないもの:** 地図に、上の7本以外の道路・通路。

### STAGE 05 — 最後の目撃者（複合条件の連鎖／5本）

**画面:** 5枚の証拠写真A〜Eと地点1〜5を1対1に対応させる。

地点の特徴:
- 1: 格子柵、丸窓
- 2: 格子柵、石階段、煙突
- 3: 丸窓、給水塔
- 4: 石階段
- 5: 給水塔、煙突

写真の特徴と候補:
- A: 格子柵 → 1または2
- B: 丸窓 → 1または3
- C: 石階段 → 2または4
- D: 給水塔 → 3または5
- E: 給水塔と煙突 → **5のみ**

**糸口:** 2特徴が一致するE–5。残りはD–3、B–1、A–2、C–4と連鎖的に確定。  
**正解:** `E-5, D-3, B-1, A-2, C-4`。  
**写してはいけないもの:** A＝丸窓・石階段・煙突・給水塔／B＝格子柵・石階段・煙突・給水塔／C＝格子柵・丸窓・煙突・給水塔／D＝煙突（写ると D–5 に絞られ、Eと衝突する）・格子柵・丸窓・石階段／E＝格子柵・丸窓・石階段。

## 5. 素材制作方針（確定）

**フォトリアル。イラスト風にしない。** 場所は室内の捜査ボードと書類の積まれたデスク。屋外の壮大な背景一枚絵は用途と違う。

- ゲームに直接使える**小さな独立部品**を必要数作る。原則、個別PNG等として扱える構成にする。
- ボード面、デスク、赤い押しピン、クリップ、小さな証拠写真、地図、メモ、書類束、机上小物を分離。
- 現場写真はボードに貼る**小さな資料**としてのみ使う。単なる綺麗な街景を増やさない。
- 画像を生成する**前に**用途・必要パーツ・再利用方法を整理する。
- 正解の決め手となる写真の細部は、論理上の一致を優先して個別に検証する。
- **日付・時刻・数字・地図の道路網は、画像生成に含めず、コードで描く別レイヤーにする**（2026-11-18 追記。AI生成画像の文字・線は正確さが保証されないため）。
- 赤い紐は静止素材ではなく実装側で描画する。
- 過去の素材生成セット v0.1 はプロトタイプ候補であり、5問の証拠画像としてそのまま採用できる保証はない。
