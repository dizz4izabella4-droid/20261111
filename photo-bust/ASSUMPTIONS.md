- 2026-11-26｜開発環境｜このMacには Node.js がなかったため、公式の Node.js 24.22.3（macOS arm64）を `~/.local/node` に展開して使う｜ユーザーの承認済み。システム全体には入れていない。
- 2026-11-26｜フォルダ構成｜npm プロジェクトは `photo-bust/_src/`。`npm run build` の出力は `photo-bust/index.html` と `photo-bust/assets/` で、これをコミットする｜Pages がブランチ配信のため。`_` で始まるフォルダは Jekyll が公開対象から外すので、ソースや node_modules は公開されない。
- 2026-11-26｜デプロイ方式｜`.github/workflows/build-photo-bust.yml` は main への push で型チェック・テスト・ビルド・Chromium での動作確認を行い、ビルド結果をコミットする。`actions/deploy-pages` は使わない｜このリポジトリの Pages はブランチ配信で、既存の yawaraka ワークフローと同じ方式に合わせた。Pages の設定を変えると他の作品に影響するため。
- 2026-11-26｜Playwright のブラウザ｜`npm run shots` は Playwright 自身の Chromium を使う。入っていない場合は、キャッシュにある Playwright の headless shell（ここでは chromium_headless_shell-1223）を使う。描画は SwiftShader｜約150MBの追加ダウンロードを避けるため。CI では `playwright install` で正規のものを入れる。
- 2026-11-26｜撮影用プロジェクトファイル｜M1 の撮影用プロジェクトは JSON（`_src/projects/default.json`、`formatVersion: 1`、`preset` と `params`）。値は内部単位（m・度・指数）｜`*.bust.zip` 形式は M5 の範囲のため。
- 2026-11-26｜UV と格子密度｜UV は各プリセットで固定の一様格子（u_j = j/segments、v_i = i/(rings−1)、u=0.5 が前の正中線）。格子線の実際の位置は、パラメータで決まる単調な密度写像で胸・乳頭に寄せる。そのため v は高さに対して単調だが比例はしない｜仕様の「頂点数とUV配置はプリセットごとに固定」と「胸の部分を密に」を両立させるため。胸の位置は 30〜44cm と大きく動くので、固定した帯では胸全体を密にしきれない。
- 2026-11-26｜格子の割り当て｜周方向：胸の帯に 38%、乳頭の帯に 32%、残り 30%。高さ方向：胸 40%、乳頭 20%、残り 40%。そのため背中・脇腹の格子は粗い（Standard で約2〜3cm 間隔）｜胸以外の細かさは優先度が低いという仕様のため。
- 2026-11-26｜周径を正確に測るための輪の配置｜ウエストとアンダーバストの高さに、ちょうど1本ずつ輪が来るように格子を合わせた｜メッシュを切った周径が ±1% に入るよう、輪の間の補間誤差をなくすため。
- 2026-11-26｜UV の継ぎ目とふた｜u=0 と u=1 の列（背中の正中線）は位置が同じ頂点を複製する。首と下端のふたは平らな法線の別頂点で、UV は v=0 / v=1 に置く。水密性テストでは位置が同じ頂点を同一とみなして調べる｜テクスチャと平らな面の陰影のため。
- 2026-11-26｜GLB の UV｜TEXCOORD_0 は glTF の決まり（左上が原点）に合わせて (u, 1−v) で書き出す｜glTF の UV 原点の定義に合わせるため。
- 2026-11-26｜仕様にない基準の高さ｜脇＝胴の高さ−11cm、肩関節＝−6.5cm、肩の上端＝−3cm、首の切断面＝首の付け根＋3cm。各高さの断面の幅・厚み・角の丸み（超楕円の指数）は仮の値｜仕様に指定がない。体型パラメータから決まる値にしてある。
- 2026-11-26｜基準の高さの順番の補正｜へそ < ウエスト < アンダーバスト < 胸 < 脇 の順番が崩れる組み合わせ（例：へそ10cm・ウエスト8cm）では、最小1〜3cmの間隔をあけるよう高さをずらし、画面に警告を出す。その場合、周径はずらした後の高さで守られる｜範囲内でも物理的にありえない組み合わせがあるため。
- 2026-11-26｜肩の切断面｜各断面の x を ±肩幅/2 で切りそろえて、平らな切断面を作る（腕用の別のふたは作らない）。切断面のふちでは法線を平均しているので、陰影が少しなめらかに見える｜仕様5.1-4の「粗い近似でよい」の範囲。メッシュは水密のまま。
- 2026-11-26｜胸の変形方向｜胴の法線方向ではなく、胸の中心の高さで、体の正面から32cm後ろの正中線上の点から放射状に押し出す｜法線方向では、張り出し120mmのとき脇のくぼみで面が折り返した（テストで交差を検出）。放射方向なら、点が自分の放射線上を動くだけなので、離散化した後も面が裏返らない。
- 2026-11-26｜外向きの角度・下垂の実現方法｜外向きの角度は、頂点（ドームの頂上）を外側へずらして表す（ずらす量＝張り出し×tan(角度−その位置での変形方向の角度)、付け根の半幅の±35%まで）。下垂は、頂点を付け根の半分の高さの最大30%下げて表す｜面を傾けて押し出すと折り返しが起きるため、高さの場だけで表した。
- 2026-11-26｜「大きさ（ボリューム）」の意味｜張り出し（mm）を固定したまま、ドームの丸み（形の指数）を変えて体積を増減させる。大きさでは張り出しは変わらない｜「張り出し」が別の mm 指定のパラメータとしてあるため。
- 2026-11-26｜上側・下側の丸み｜丸み 0 → 釣鐘形（指数 k=2, m=2.6）、100 → 丸く張った形（k=5, m=1.6）。m を常に 1 より大きくして、付け根でなめらか（C1）につながるようにした｜仕様5.3-1（しわを作らない）。
- 2026-11-26｜乳房下溝｜胸の変形はアンダーバストの高さより下には及ばない（1.2cm かけてなめらかに 0 にする）。高さ位置がアンダーバストに近いと、胸の下側がこの線で押さえられる｜解剖学的に乳房は乳房下溝より上にある。アンダーバスト周径を胸が変えないようにするため。
- 2026-11-26｜乳頭の位置の符号｜左右（X）は＋が外側（左右とも）、上下は＋が上｜左右対称で扱うため。
- 2026-11-26｜乳頭の直径の測り方（テスト）｜乳頭の高さの半分での全幅を測る。パラメータの約0.85倍になる｜「測った直径」の定義が仕様にないため。単調性はこれで判定する。
- 2026-11-26｜GLB のランドマーク位置｜肩関節＝切断面の中心（x=±肩幅/2、肩関節の高さ、断面の中央）。首の付け根＝首の付け根の高さでの断面の中心。へそ＝へその高さの前の正中線上の表面。乳頭＝乳頭の先端。ウエスト＝ウエストの高さの左右の側面｜仕様に位置の定義がないため。リギングで使いやすいよう、関節は断面の中心にした。
- 2026-11-26｜既定のプリセット｜指が主の入力（pointer: coarse）で、画面の短い辺が 900px 未満なら Light、それ以外は Standard｜仕様11.1の判定方法を具体化した。
- 2026-11-26｜照明｜ビューアも固定視点の撮影も、照明はカメラに対して固定（左上からの主光源・半球光・弱い補助光）。背面の撮影も正面と同じ明るさになる｜4方向を同じ条件で比べられるようにするため。
- 2026-11-26｜材質｜画面表示は MeshLambertMaterial（つやなし）。GLB は metallic 0・roughness 1、色は #3A6FD8 をリニアに変換した値｜仕様5.1-6の「つやなし」。
