================================================================
 モンスタースミス 説明書（現在の仕様）
 3D の敵キャラを自動生成し、動き付きの GLB で書き出すツール
================================================================

■ 1. これは何か
----------------------------------------------------------------
・ブラウザ上で、敵モンスターの 3D モデルを作るツールです。
・骨格（スケルトン）とアニメーション 7 種が最初から入った
  GLB ファイルを書き出せます。ゲームエンジンに取り込んで使えます。
・同じシード（番号）からは、必ず同じモンスターが再現されます。
・ステータス（HP・攻撃など）も一緒に作り、GLB の中に入れます。

■ 2. ファイル構成
----------------------------------------------------------------
  index.html       画面（これを開く）
  monster-core.js  モンスターの生成とアニメーションの本体
  zip.js           まとめ出し用の ZIP 作成部品
  説明書.txt       このファイル
  preview/         動作確認で撮った画面画像（なくても動きます）

  ※ index.html / monster-core.js / zip.js の 3 つは、
    必ず同じフォルダに置いてください。

■ 3. 動かし方
----------------------------------------------------------------
・ファイルを直接ダブルクリックして開くと、ブラウザの制限で
  動かないことがあります。ローカルサーバー経由で開いてください。
    例:  フォルダで  python3 -m http.server  を実行し、
         http://localhost:8000/index.html  を開く
・インターネット接続が必要です（3D 描画ライブラリ Three.js
  r160 を jsDelivr から読み込みます。フォントは任意）。
・GitHub Pages など、静的なサイトとしてそのまま公開できます。
・開いたあとの URL 末尾に #s=シード&g=タイプ&t=強さ が付きます。
  この URL を保存すれば、同じモンスターをいつでも開けます。

■ 4. 画面の項目（上から順に）
----------------------------------------------------------------

【種類】
  タイプ   獣 / 虫 / 竜 / 二足 から選びます。
           体の大きさ・脚の数・翼・角の出やすさ・色の傾向・
           攻撃の動きが変わります（下の「タイプ別の特徴」）。
  強さ     序盤(1) / 中盤(2) / 終盤(3) / 強敵(4) / ボス(5)
           強いほど大きくなり、ステータスが高くなります。
           （大きさの倍率 = 0.75 + 0.15 × 強さ）
  シード   1〜999999 の番号。同じ番号なら同じ個体になります。
           番号を入れて Enter（または欄の外をクリック）で作り直し。
  [ランダムに作る]
           シードをランダムに決めて、新しい個体を作ります。
           ※ スライダーなどの手動調整はリセットされます。

【体つき】（動かすとその場で作り直されます）
  全長       体の長さ。0.6〜4.5 m
  太さ       胴体の太さ。0.12〜0.8
  脚の長さ   0.3〜1.6 m
  尻尾       尻尾の長さ。0〜4 m（0 で尻尾なし）
  脚の数     2 / 4 / 6
  色相       体の色合い。0〜1（0=赤系、0.33=緑系、0.66=青系）
  鮮やかさ   色の濃さ。0〜1
  模様       なし / 縞 / 斑点
  ポリゴン   低（軽量） / 中 / 高（滑らか）
             目安（同じ個体で）: 低 約650 / 中 約1,200 /
             高 約3,800 三角形。ゲームの負荷に合わせて選びます。
  翼         なし / あり
  目         0〜6 個
  角         0〜6 本
  トゲ       背中のトゲ。0〜8 本

【動きを確認】
  待機 / 歩く / 走る / 攻撃 / 被弾 / やられ / 咆哮
  押すとその動きを再生します。
  ・待機・歩く・走る は繰り返し再生されます。
  ・攻撃・被弾・咆哮 は 1 回再生して、自動で待機に戻ります。
  ・やられ は倒れたままで止まります（別の個体を作ると戻ります）。

【視点】
  斜め / 正面 / 側面 / 真上   カメラの位置を切り替えます。
  並べ表示・まとめ出しで色と模様を引き継ぐ
           チェックを入れると、並べ表示とまとめ出しの全個体に、
           今の色相・鮮やかさ・模様を揃えて適用します。
           （体つきは個体ごとに変わります）
  [並べて見比べる（5体）]
           今のタイプ・強さで、シードを順に変えた 5 体を
           横に並べて、同じ動きで再生します。
           気に入った個体をクリックすると、その個体を
           編集画面に持ってきます。もう一度押すと閉じます。
  巡回デモ（足が滑らない速度で歩く）
           チェックを入れると、床の上を円を描いて歩きます。
           「走る」「待機」を押すと速度が変わります。
           歩行・走行の確認用です。
  自動で回転
           チェックを入れると、ゆっくり回って全体を見せます。
  ※ 画面上でマウスをドラッグすると回転、ホイールで拡大縮小。

【ステータス】（直接書き換えできます）
  属性     無 / 炎 / 氷 / 雷 / 毒 / 闇
           変えると目の色も変わります。
             炎=橙  氷=水色  雷=黄  毒=黄緑  闇=紫  無=黒
  弱点     属性と同じ選択肢から選びます（自動では連動しません）
  HP / 攻撃 / 防御 / 速度
  サイズ   （表示のみ）幅 × 高さ × 奥行き（m）
  三角形   （表示のみ）ポリゴン数

  自動で決まる値の目安（強さ = t）:
    HP   約 30 × t の 1.7 乗      攻撃 約 5 × t の 1.4 乗
    防御 約 3 × t の 1.3 乗       速度 1.0〜2.2
    （どれも ±20% 程度ばらつきます）
    属性はシードごとにランダム。弱点の初期値は次のとおり。
      無→雷  炎→氷  氷→炎  雷→毒  毒→炎  闇→雷

【ボタン】
  [GLB を書き出す]   今表示している個体を GLB で保存します。
                     （ファイル名: monster_タイプ_シード.glb）
  [JSON]             今の仕様（体つき・色・ステータスなど）を
                     JSON で保存します。
  [まとめて ZIP]     横の欄で体数（5 / 10 / 20 / 50）を選びます。
                     今のタイプ・強さで、シードを 1 ずつ増やした
                     個体を GLB で書き出し、manifest.json と一緒に
                     ZIP にまとめます。
  [JSON を読み込む]  [JSON] で保存したファイルを読み込み、
                     その個体を再現します。

  注意:
  ・まとめて ZIP / 並べ表示 の個体は「自動生成のまま」です。
    手で書き換えたステータスや体つきは反映されません。
    引き継がれるのは、ポリゴン数（常に）と、
    色・模様（チェックを入れたとき）だけです。

■ 5. タイプ別の特徴
----------------------------------------------------------------
              獣          虫          竜          二足
  背骨の数    5〜7        4〜6        7〜9        5〜6
  全長(m)     1.4〜2.2    0.9〜1.5    2.2〜3.4    1.2〜1.8
  尻尾(m)     0.6〜1.2    0〜0.2      1.4〜2.4    0.4〜0.9
  脚の数      4           6           2 または 4  2
  角          0〜2        0〜2        2〜4        0〜2
  目          2           2〜4        2           2〜3
  色の傾向    赤〜橙      緑          青〜紫      紫〜桃
  翼          15%         15%         必ず あり   15%
  攻撃の動き  噛みつき    体当たり    振り下ろし  振り下ろし
  ※ 全長・脚の長さ・尻尾は「強さ」で大きくなります。
  ※ 縞は約 50%、斑点は約 40%（縞がない個体のみ）で出ます。

■ 6. 動き（アニメーション）の一覧
----------------------------------------------------------------
  名前    長さ    再生       内容
  Idle    2.4 秒  繰り返し   呼吸で胸が沈み、頭が見回し、尻尾が揺れる
  Walk    1.0 秒  繰り返し   歩行。足が地面を滑らない
  Run     0.6 秒  繰り返し   走行。体が前に傾き、弾む
  Attack  0.8 秒  1 回       タイプ別の攻撃（下記）
  Hit     0.45 秒 1 回       のけぞり、後ろへ押される
  Die     1.4 秒  1 回       よろけて崩れ、横倒しになる
  Roar    1.8 秒  1 回       体を反らして翼を広げて吠える（登場演出向き）

  攻撃の動き:
    噛みつき（獣）   頭を引いてから前へ突き出す
    体当たり（虫）   体を沈めてから前へ踏み込む
    振り下ろし（竜・二足）  のけぞってから前へ叩きつける

  ・尻尾がある個体は、どの動きでも尻尾が連動して動きます
    （歩きは左右に揺れ、攻撃は振り回し、やられは垂れ下がる）。
  ・足は地面に付いたまま動きます（足先 IK を計算して
    キーフレームに焼き込み済み）。ゲーム側で IK は不要です。
  ・1 回再生の動きは GLB 内に「ループしない」という情報を
    持ちません。ゲーム側で、Idle / Walk / Run はループ、
    それ以外は 1 回再生に設定してください。
    Die は最後の姿勢で止める設定にします。

■ 7. 書き出す GLB の仕様（ゲーム側で読むときの決まり）
----------------------------------------------------------------
  座標     Y 軸が上、1 単位 = 1 m、正面 = +Z、左右 = ±X
  メッシュ 1 つ（名前 MonsterMesh）、スケルトン 1 つ
  材質     1 つ（名前 MonsterSkin）。頂点カラーで着色。
           テクスチャ画像はありません。
  ルート   ノード名 Monster
  ボーン名
    root                       足元の原点（移動の基準）
    spine_0 … spine_(N-1)      背骨。spine_0 が尻尾側、最後が頭
    hip_L0 / knee_L0           左の脚（前から順に 0, 1, 2）
    hip_R0 / knee_R0           右の脚
    tail_0 … tail_4            尻尾（5 本）。spine_0 の先につく。
                               尻尾がある個体のみ
    wing_L / wingtip_L         左の翼（付け根・先端）※翼がある個体のみ
    wing_R / wingtip_R         右の翼
  クリップ名  Idle / Walk / Run / Attack / Hit / Die / Roar
              （キーフレームは 20 コマ/秒で焼き込み）

  GLB のルートノードの extras（追加情報）に、次が入ります:
    generator   "monster-smith"
    spec        生成仕様（シード・体つき・色・攻撃スタイルなど）
    stats       tier / element / weakness / hp / atk / def / speed
    bounds      size [幅,高さ,奥行き] / height / capsuleRadius
                （当たり判定用）/ tris（三角形の数）
    locomotion  Walk と Run の移動速度（m/秒）
                歩き・走りで足が地面を滑らない速度です。
                ゲーム側の移動速度に使えます。
    clips       クリップ名の一覧

  まとめ出し ZIP の manifest.json には、個体ごとに
  file / genre / seed / stats / bounds / locomotion / clips が入ります。

■ 8. 保存・共有・復元
----------------------------------------------------------------
  ・[JSON] で保存 → [JSON を読み込む] で同じ個体に戻せます。
    （シード・体つき・色・模様・ポリゴン数・ステータス・
      手動で変えた値も保存されます）
  ・URL の #s=…&g=…&t=… でも、手を加える前の個体を再現できます。
    （スライダーなどの手動調整は URL には入りません）

■ 9. 既知の制限・未実装
----------------------------------------------------------------
  ・色は頂点カラーのみで、テクスチャ模様（鱗など）はありません。
  ・翼は 1 枚の板状（膜）です。細かい羽根の表現はありません。
  ・走りは、算出した移動速度より実際の足の動きが約 5% 遅めです。
    また、接地中の足先の高さが最大約 3cm 上下します。
    歩きは速度がほぼ一致します。
  ・虫タイプの攻撃で、足先が地面に最大 3〜4cm めり込む
    瞬間があります。
  ・歩きでは、胴体の左右のうねりは頭側のみです（足が横に
    滑るのを防ぐため）。代わりに尻尾が左右に揺れます。
  ・並べ表示・まとめ出し・巡回デモは、手動で変えた
    ステータス・体つきを反映しません（上の注意を参照）。
  ・実機の描画速度は未測定です。動作確認は、パソコン上の
    ヘッドレスブラウザ（GPU なしの描画）と Node で行いました。
  ・サイトへの反映（monster/ フォルダの追加、作品台帳
    data/works.json への追記）は、まだ行っていません。

■ 10. 使用技術
----------------------------------------------------------------
  Three.js r160（WebGL）／ Skeleton・SkinnedMesh ／
  背骨カーブ＋半径プロファイルによる胴体生成 ／
  mulberry32 乱数（同じシードで同じ結果）／
  2 ボーン IK を毎フレーム解いてキーフレームに焼き込み ／
  GLTFExporter（GLB）／ OrbitControls ／ 自前 ZIP（無圧縮）／
  ES Modules + importmap（ビルド不要）／ GitHub Pages（静的公開）
