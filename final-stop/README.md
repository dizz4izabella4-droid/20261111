# HANDS UP

パトカーで逃走車を追跡し、窓が開いたらスワイプで当てて止め、降車命令（英語）で逮捕する単一HTMLのミニゲーム。
設計書：claude.ai の「HANDS UP 設計書 v2（Opus）」。設計の B0〜B5 まで実装済み（v1.0 テスト版）。実機（iPhone）での確認待ち。

- B1 絵：夜の道路・街灯・遠景、車の後ろ姿（逃走車とパトカーで共通の描画関数）、窓の輪と矢印
- B2 音：Web Audio の合成音（エンジン、サイレン3種、衝突、無線、ドア、手錠）。マナーモードではiOSの標準の動きで鳴らない
- B3 衝突：ヒットストップ、画面の揺れ、火花、白フラッシュ、3回目はスローと周辺減光、停止時の砂煙
- B4 イベント：照射ライト、ハザード、ドア、容疑者のポーズ（車内→降車→伏せ）、警官、手錠のきらめき、ARREST のゆっくりしたズーム
- B5 仕上げ：END 画面の配置、テスト一式、ドキュメント

- `index.html` … 本体。`/*@TESTABLE*/` の区間（CONFIG と CORE）が純ロジック
- `_test/core.test.mjs` … `node final-stop/_test/core.test.mjs`（CORE 単体）
- `_test/shots.py` … `python3 final-stop/_test/shots.py`（Playwright で縦横を撮影し、逃走車の大きさを設計書の表と照合）
- URL: `?debug=1`（状態表示）／`?auto=1`（自動プレイ）／`?seed=N`／`?shot=HIT2&t=0.5`（その場面で止めて撮影）

## v1.3 コマンド・被弾まわりの再編成
- 音声は**言語判定なし**。マイクに音（音量）が入っていれば OK。途切れても約0.9秒は聞き続ける。
- タイトルで「マイクをオンにしないとクリアできません」と表示。START でマイク許可を求め、拒否されたら開始しない。テスト用に `?nomic=1`。
- YOURTURN は5秒。声が出なければ犯人に撃たれて「YOU'RE DEAD..」→タイトルへ。
- 声が途中で切れたら同僚 REYES が「One more, please!」（+2秒、最大2回）。
- 喋っている間、REYES は拳銃を構えて頷き「Good!」。言い終えると GOOD/GREAT/EXCELLENT/PERFECT を派手に表示し、REYES が褒める。お手本も REYES。
- 逃走車は被弾ごとにガラスが割れて飛び散る（GLASS BREAKER 方式）：1=接触側テール＋リアガラスにヒビ、2=反対側テール＋ガラス一部落下、3=残りが全壊。

## v1.26 無線を静寂の中で

## v1.27 破損を大きく・スピン・ガラス4倍

## VFX 第2段階（2026-11-21）
- ベースの426×240／240×426世界解像度と640×360／360×640の座標系を維持。VFX専用バッファを世界解像度で再利用し、HUD・字幕には合成しない。
- パトライトは車体ポリゴンの向きと光源距離に応じて面ごとに反射。建物・植物には面単位の弱い赤青照射、街灯とパトライトの下には途切れた路面反射筋を追加。
- 街灯、パトライト、衝突点、火花、ガラスの短い反射だけを独立レイヤーで発光。世界の輪郭やポリゴンにはぼかしをかけない。
- 衝突光は数フレームで消え、ガラス片の反射は破片ごとに時間差をつけた。煙の多角形、既存の破壊段階・ヒットストップは維持。粒子数は最大720に抑制。
- BOOST時の近景速度線を短時間だけ増やし、既存のカメラズーム・反動・スピード線と統合。逮捕用の光柱内部には低速の粉塵を追加し、警官の足元影をポーズに追従させる。
- `?vfx=0` で今回追加した面照明・反射筋・発光・粉塵・BOOST近景線を無効化、`?vfx=1` または指定なしで有効化。比較例：`?shot=HIT2&t=0.5&seed=1&vfx=0` と同じURL末尾を `vfx=1` に変更。
- 入力・判定・音声・進行ロジックはVFX層から分離。診断用 `window.__probe` は従来どおりゲーム状態・車両座標を確認可能。
- 公開版をChrome・1280×720で確認。`OPEN_PARK`、`APPROACH`、HIT 1/2/3、`PULLOVER`、`EVENT`、`PREVIEW`、`YOURTURN`、`ARREST`、`END`、`DEAD` が表示され、デバッグ表示は60fps。`HIT2` の同一seed／shot／timeでVFX ON/OFFを表示し、車体のポリゴン輪郭は保たれ、ゲーム状態値も一致。
- 粒子配置には既存の非決定乱数が使われているため、ON/OFFの停止画の粒子個別位置は一致しない。390×844、844×390、1366×768、1920×1080の比較とiPhone Safari実機確認・FPS計測は未実施。ローカルの `file://` 表示は実行環境のブラウザ安全ポリシーにより拒否された。
