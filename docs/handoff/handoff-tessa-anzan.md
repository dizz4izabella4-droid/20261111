## 2. ゲームの流れ（現状）
1. タイトル → 難易度選択（電子ノイズの演出のあと開始）。
2. 旧校舎1Fの廊下（ワイヤーフレームの3D、Canvas）を前へ進む。マス数が難易度ごとに違う。後ろへ戻ると死神に斬られてゲームオーバー。
3. 歩くと確率で敵に遭遇。女神は**任意で召喚**（戦闘には参加しない飾りで、身代わりで被弾するガードと、セリフを言う）。召喚しない縛りプレイもできる。
4. 暗算の答えをテンキーで入力。桁がそろうと自動判定。速いほど攻撃回数が増える。レベルが上がると項数が増える。
5. 突き当たり到達でクリア（リザルト）。クリア1周ごとに、**装備またはポーションを1つ**得て、**女神が1名仲間入り**する。記録はブラウザの localStorage（キー `anzan_rec_v1`）に保存。
6. エンディング（スタッフロール、`ending.mp3`）あり。役職は英語で読める文字、タイトルと名前だけが読めない記号。RECORD はタイトルには出さず、STATUS と同じく待機中・戦闘中に画面上部とパッドのボタンから開く（リザルト／ゲームオーバー画面からも開ける）。

難易度（`DIFFS`）: 激甘・甘口・中辛・辛口・デス・電卓。デス以外は、初期の仲間は既存の5人（lumi・fers・roza・miri・lyum）。デスは女神なしのソロ（主人公HP1、復活3回、女神の愛で復活）。電卓は4〜5桁の四則演算。

## 3. 主なデータとコード（`index.html` 内）
- `GODDESS_POOL`（名前・最大HP・ひとこと）／`LINES[id]`（場面別セリフ。場面: ok・fast・crit・miss・guard・hurt・start・win・lvup・walk・clear・low・back・enemy）／`SUMMON_LINES`／`FALL_LINES`（力尽きるとき）／`REVIVE_LINES`／`GODDESS_STATS`／`GODDESS_SKILLS`／`APPEARANCE`。
- 既存8名: lumi・fers・roza・miri・lyum・sylph・nerei・volta（`ALL_IDS`）。
- **追加の30名**（GOD-02）: `NEW_GODDESS_DATA`（コンパクトJSON）。直後のIIFEが、上記の各表に流し込む。`JOIN_IDS = ALL_IDS.concat(NEW_IDS)` が仲間入りの順（既存8名のあと、番号順に G→C→O）。休息明け・デス復活・ステータスの「ひとこと」は `NEW_META[id]`。表示の数値（HP・ステータス）は名前から決まる飾りで、意味はない。

## 4. ユーザーの希望・決定事項
- 召喚するのは**悪魔でなく女神**。名前はすべて創作（実在の神名・既存作品の名は使わない）。
- 女神は辛辣（ツン中心）。口の悪さは**愛嬌**として採用済み。句読点なしのセリフもそのまま。
- 追加の女神30名は、ユーザーがセリフ（文章）を各AIに作らせた。絵はまだない。絵の内容はユーザーが指示する（ChatGPT の絵の仕上がりは好まない）。
- 難易度に関わらず、初期の仲間は5人。召喚するかしないかはプレイヤー次第。デスだけは一人。
- ゲーム内の説明は基本出さず、遊べば分かる作りに。
