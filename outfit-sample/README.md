# 衣装サンプル（スペアボディ用）

スペアボディの素体（身長153.3cm、骨59本）に、ドレス・帯・フード付きマントを着せたサンプル。

- `spare_body_dressed.glb` : 素体＋衣装。傀儡の「体（GLB）を開く」で読み込める。
- 服のメッシュ名は `cloth_` で始まる。素体と同じ骨にスキニングしている。
- 服の頂点属性 `_MAX_DISTANCE`（m）は、布を揺らす処理を入れるときの可動範囲の目安（現状は未使用）。

## 作り直し

    node dress.mjs <素体.glb> <出力フォルダ>   # 形を作り、布の落ち方を計算
    node build.mjs <素体.glb> <出力フォルダ>   # 色・骨の重みを付けてGLBを書き出し
    node verify.mjs <素体.glb> <出力フォルダ>/spare_body_dressed.glb

追加のライブラリは不要。`viewer.html` は確認ページのひな形（`__GLB__` を GLB の base64 に置き換える）。

## 制限

- `dress.mjs` の高さや首まわりの座標は、この素体に合わせた固定値。体型が違う素体には調整が必要。
- 布の揺れの計算は実行時に行わない。脚や肘を大きく曲げると素体が服を突き抜ける。
- 衣装は 18,558 頂点・35,516 三角形。ゲーム用の軽量版はまだ無い。
- テクスチャは無く、頂点カラーのみ。
