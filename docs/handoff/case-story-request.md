# 依頼：連携アプリの本物の事件「館の連続殺人」の中身を作る（チャットへの引き継ぎ）

最終更新: 2026-11-20

この文書を、話の設計を担当するチャットにそのまま渡す。
仕組み（3画面の連携・マーカー・ボード・フロッピー・追体験・答え合わせ）はできている。ここで作ってほしいのは**事件の中身だけ**。
できあがった中身は、Claude Code 側で試作用ダミー事件 X-01 と同じ形に流し込む。

---

## 1. どんな遊びか（前提）

3つの画面を左右にスワイプして行き来する、推理の遊び。

| 画面 | 役目 | プレイヤーがすること |
|---|---|---|
| 左：資料保管庫（書庫） | 当時の捜査資料（調書・写真台帳など）を読む | 気になる語句を**指でなぞってラインを引く**。引いた資料は、引いた語句（付箋）ごとボードに載る |
| 中央：レッドライン（ボード） | 推理を組み立てる | 資料・記事・証拠にピンを刺し、**ピンどうしを色つきの紐でつなぐ**。メモ・手書きもできる |
| 右：iz2611（架空のレトロ端末） | 専用フロッピーを挿して使う | **新聞縮刷版を日付で検索**して読む・記事をボードに貼る。**事件当日の朝を再現（追体験）**して新証拠を見つけ、最後に**真相**がわかる |

- 流れ：保管庫で事件ファイルを開く → 資料を読んでラインを引く → ボードで紐を3本つなぐと、保管庫に専用フロッピーが現れる → 端末に挿す → 新聞を調べる → 追体験で新証拠 → 真相 → ボードの紐と真相を照合（✓／✗と「見つかっていない数」だけ出す。**答えそのものは見せない**）。
- 追体験で介入すると、端末の中の世界では救いがあることもある。**現実（記録）は変わらない**が、真相はわかる。

## 2. 決まっていること（変えない）

- 新しい架空の事件を1件。**館の連続殺人（3件）**。舞台は嵐や雪で孤立した山荘・洋館。
- 人物 **6〜8人**、保管庫の資料 **10〜15点**。
- 時代は**二層**：当時（事件）と現在。現在側のプレイヤーは、保管庫を整理する**再捜査者**。当時の捜査資料が保管庫に残っている。
- 追体験の場面は、**最初の殺人が発見される朝の1場面だけ**。
- 新聞は端末でしか読めない（保管庫には無い）。同じ紙面に関係の薄い事故や話題を混ぜ、**一見して見落とすような記事**を作る。
- ゴールは、ボードの紐と真相の照合（答え合わせ）。
- 実在の企業・機種名・人物は使わない。端末名は iz2611。

## 3. 作ってほしいもの

### (1) 事件の全体と真相（作り手用。プレイヤーには最後まで見せない）
- 3件の殺人それぞれの、被害者・時刻・場所・手口。
- 犯人と動機、トリック、孤立した館で成り立つ理由。
- 当時の捜査がどこで誤ったか（なぜ未解決／誤認のまま記録が残ったか）。
- 時系列（分単位で書けるところは分単位）。

### (2) 人物表（6〜8人）
名前（読み）・年齢・職業・館にいた理由・被害者との関係・事件当夜の申し立て。

### (3) 保管庫の資料（10〜15点）
1点ずつ次の形で。
- 整理番号（例 `X-02-001`。番号は仮でよい）、作成年月日、題名、作成部署、本文。
- 本文は1点 **200〜600字** 目安。段落は改行で分ける。写真・見取図は「写真一　〜」のように**文章で**写っているものを書く（画像は使わない）。
- **手掛かりは本文中の短い語句（30字以内）でラインを引ける形**にする。手掛かりが図や数字の比較だけにならないようにする。
- 誤った手掛かり・関係のない記述も混ぜる。

### (4) 新聞（端末の縮刷版）
- 新聞名（架空）、収録期間（例 1月1日〜3月31日）。
- 紙面を日付ごとに。1つの紙面は記事 **3〜5本**、大きさ L（大見出し）／M／S（小さな記事）を混ぜる。
- 各記事：大きさ、見出し、本文（50〜200字）。
- **見落としやすい記事（S）を最低2本**。資料の語句と組み合わせて初めて意味がわかるもの。
- 紙面がない日に検索すると「記事なし」と出る。どの日付を探すべきかは、資料の中の日付から推理できるようにする。

### (5) 追体験（最初の発見の朝・1場面）
- 時刻と場所、最初の一文（状況）。
- 調べられる所 **5〜7か所**。各所の文（1〜3文）。
- そのうち **新証拠 2〜3点**：題名（30字以内）と説明（100字以内）。資料や新聞と組み合わせて推理に使うもの。
- **介入 1つ**：選択肢の文と、端末の中だけで起きる「救い」の文。最後に「記録は変わらない」とわかる一文。
- 真相の文（プレイヤーに見せる版。150〜300字）。

### (6) 答え（正しいつながり）
- ボードの物どうしの**正しいつながり 5〜8本**。それぞれ「Aの物 — Bの物 ／ 何がわかるか（30字以内）」。
- 物は、資料（整理番号）・新聞記事（日付＋見出し）・新証拠（題名）のどれか。
- 各つながりが、**資料・記事・証拠の文面だけから推理できる**こと（作り手の頭の中だけにある情報を使わない）。
- 答えは一意になるようにする（似たつながりで別解ができないか確かめる）。

### (7) 名前まわり
- 事件名（保管庫の事件ファイルの名前）、ひとこと説明。
- 専用フロッピーのラベル（英字の題名 20字まで・日本語のひとこと 12字まで）。

## 4. 書き方の注意
- 全部架空。実在の地名を使うなら、ありふれた一般名詞の範囲で。
- 残酷な描写は、捜査資料の文体で淡々と。過度な描写はしない。
- 日付・時刻は資料・新聞・追体験で矛盾しないよう、最後に一覧で突き合わせる。
- 参考：試作用ダミー事件 X-01 の中身（形の見本）は `iz2611/cases/x-01/index.html`（新聞・追体験・真相）と `shoko/index.html` の `shoko-link-data`（資料）にある。

## 5. 渡し方
上の (1)〜(7) を、見出しつきの文章でまとめて Claude Code に渡す。JSON にする必要はない（流し込みは Claude Code 側で行う）。
