- 2026-11-26｜UV と格子密度｜UV は各プリセットで固定の一様格子（u_j = j/segments、v_i = i/(rings−1)、u=0.5 が前の正中線）。格子線の実際の位置は、パラメータで決まる単調な密度写像で胸・乳頭に寄せる。そのため v は高さに対して単調だが比例はしない｜仕様の「頂点数とUV配置はプリセットごとに固定」と「胸の部分を密に」を両立させるため。胸の位置は 30〜44cm と大きく動くので、固定した帯では胸全体を密にしきれない。
- 2026-11-26｜格子の割り当て｜周方向：胸の帯に 38%、乳頭の帯に 32%、残り 30%。高さ方向：胸 40%、乳頭 20%、残り 40%。そのため背中・脇腹の格子は粗い（Standard で約2〜3cm 間隔）｜胸以外の細かさは優先度が低いという仕様のため。
- 2026-11-26｜周径を正確に測るための輪の配置｜ウエストとアンダーバストの高さに、ちょうど1本ずつ輪が来るように格子を合わせた｜メッシュを切った周径が ±1% に入るよう、輪の間の補間誤差をなくすため。
- 2026-11-26｜UV の継ぎ目とふた｜u=0 と u=1 の列（背中の正中線）は位置が同じ頂点を複製する。首と下端のふたは平らな法線の別頂点で、UV は v=0 / v=1 に置く。水密性テストでは位置が同じ頂点を同一とみなして調べる｜テクスチャと平らな面の陰影のため。
- 2026-11-26｜GLB の UV｜TEXCOORD_0 は glTF の決まり（左上が原点）に合わせて (u, 1−v) で書き出す｜glTF の UV 原点の定義に合わせるため。
- 2026-11-26｜仕様にない基準の高さ｜脇＝胴の高さ−11cm、肩関節＝−6.5cm、肩の上端＝−3cm、首の切断面＝首の付け根＋3cm。各高さの断面の幅・厚み・角の丸み（超楕円の指数）は仮の値｜仕様に指定がない。体型パラメータから決まる値にしてある。
- 2026-11-26｜基準の高さの順番の補正｜へそ < ウエスト < アンダーバスト < 胸 < 脇 の順番が崩れる組み合わせ（例：へそ10cm・ウエスト8cm）では、最小1〜3cmの間隔をあけるよう高さをずらし、画面に警告を出す。その場合、周径はずらした後の高さで守られる｜範囲内でも物理的にありえない組み合わせがあるため。

- 2026-11-26｜胸の変形方向｜胴の法線方向ではなく、胸の中心の高さで、体の正面から32cm後ろの正中線上の点から放射状に押し出す｜法線方向では、張り出し120mmのとき脇のくぼみで面が折り返した（テストで交差を検出）。放射方向なら、点が自分の放射線上を動くだけなので、離散化した後も面が裏返らない。
- 2026-11-26｜外向きの角度・下垂の実現方法｜外向きの角度は、頂点（ドームの頂上）を外側へずらして表す（ずらす量＝張り出し×tan(角度−その位置での変形方向の角度)、付け根の半幅の±35%まで）。下垂は、頂点を付け根の半分の高さの最大30%下げて表す｜面を傾けて押し出すと折り返しが起きるため、高さの場だけで表した。
