モンスタースミス

敵キャラを作って、動き付きの GLB で書き出します。

種類
体つき
動きを確認
視点
ステータス
使用技術
描画
Three.js r160（WebGL）
骨格・スキン
Skeleton / SkinnedMesh（1メッシュ・1スケルトン）
体の生成
背骨カーブ＋半径プロファイルのチューブ、円錐・球のパーツ結合
乱数
mulberry32（同じシードで同じ結果）
アニメ
手続き生成 → キーフレームに焼き込み（AnimationClip）
書き出し
GLTFExporter（GLB / extras にステータス）
操作
OrbitControls（視点プリセット・自動回転）
翼
2関節（付け根＋先端）の膜メッシュ＋しなる羽ばたき
構成
ES Modules + importmap（ビルド不要）
移動速度
歩き・走りの足が滑らない速度を算出し GLB に記録
LOD
ポリゴン数 低/中/高（半径分割・リング数・パーツ分割）
まとめ出力
自前 ZIP（無圧縮）＋ manifest.json
比較表示
複数体の同時生成・同時再生、床面レイキャストで選択
公開
GitHub Pages（静的サイト）
ドラッグで回転 / ホイールで拡大
