# ASSUMPTIONS（判断の記録）

書式：日付｜項目｜判断｜理由

- 2026-11-26｜置き場所と名前｜リポジトリ 20261111 の `body-motion/`、仮の名前「動く素体」。photo-tex（凍結）は変更せず、必要なファイル（胴・胸のモデル、GLB 書き出し、撮影スクリプト）を写して使う｜ユーザーの指示（「他パーツも組み合わせて動かせる体を作る」）。凍結した作品を壊さないため。
- 2026-11-26｜取り込む動き｜作品「モーション」が保存する JSON（`format: "dizz-mocap-v1"`：33点の関節位置、12本の骨の向き、腰の位置、+Y 上・+Z 前・メートル）を第2段階で取り込む。指（「指モーション」）は後で｜ユーザーの指示。
- 2026-11-26｜座標｜メートル、+Y 上、+Z 体の前、+X 体の左、床が y = 0、原点は両足の中央。モーションの JSON と同じ向き｜取り込む動きと合わせるため。
- 2026-11-26｜胴の高さの基準｜胴のパラメータの高さは股（胴の下端）から測る。photo-tex の値（下端＝へその少し下から）は +14cm して移した｜全身では股が胴の下端になるため。14cm は成人女性の股〜へそと photo-tex の下端〜へその差の目安。
- 2026-11-26｜骨盤（腰）の形｜photo-tex の胴の下に、股（脚の間で丸く閉じる小さな断面）、骨盤の下部、ヒップ（ヒップ周径どおりの断面、前45%・後55%の厚み＝お尻）を足した。股関節は股の 7cm 上｜全身にするため。股の断面を小さくして丸く閉じると、太ももとの境目の線が目立たなかった。
- 2026-11-26｜肩の切断面の範囲｜photo-tex では胴全体の幅を肩関節の位置で切っていたが、肩の高さの帯だけに限った（脇の 2〜6cm 下で効き始める）｜ヒップが肩より広い体型でお尻まで平らに切られていた（テストで発見）。
- 2026-11-26｜手足と頭のつくり｜腕・脚は楕円断面の筒（周径の指定どおりの太さ、両端は丸く閉じる）、首は筒、頭・手・足は直方体（仮）。各部位は別々の閉じた形で、関節で重なる（マネキンのような作り）｜ユーザーの指示（「顔や手足はとりあえず保留、単純四角でいい」）。まず動かせることを優先。
- 2026-11-26｜骨格と結びつけ｜骨 17 本（腰・背骨・胸・首・頭、左右の上腕・前腕・手、太もも・すね・足）。各部位は 1 本の骨に固定、胴だけは腰→背骨→胸になめらかに分けて結びつける｜「モーション」の骨（上腕・前腕・太もも・すね・足・背骨・肩のライン）をそのまま動かせるようにするため。
- 2026-11-26｜立ち姿｜脚はまっすぐ、腕は体の横から「腕の開き」（初期値 18°）だけ開いた姿勢を基準姿勢にする｜腕が胴（胸）と重ならず、取り込んだ動きの向きを当てやすいため。
- 2026-11-26｜初期値｜胴・胸は photo-tex で調整した女性プリセットの値、手足・頭は成人女性（身長約 160cm）のおおよその値（統計データではない仮の値）。男性プリセットは仮｜ユーザーが調整していく前提。
- 2026-11-26｜GLB 書き出し（第1段階）｜立ち姿のメッシュ 1 つと、関節ごとの空のノード（`J_<骨の名前>`）。骨格（スキン）と動きつきの書き出しは第3段階｜まず形を確かめられるようにするため。
- 2026-11-26｜実験用のサンプルは男性素体｜アプリを開いたときの体型は男性（女性は体型プリセットで選べる）｜ユーザーの指示（「実験用のサンプルはシンプルなので男性素体で」）。
- 2026-11-26｜動きの当て方｜「モーション」の JSON の 33 点の関節位置から骨の回転を求める：腰＝左右の腰の線と背骨（腰の中点→肩の中点）、胸＝左右の肩の線と背骨、背骨＝腰と胸の中間、頭＝左右の耳の線と胸の上方向、首＝胸と頭の中間。腕・脚・足は、親の骨に対していちばん小さい回転で骨の向きを関節の向きに合わせる（腕や脚のねじれは関節位置からは決まらないので、ねじれは加えない）。腰と胸の回転は体の立ち姿の線を基準にする（立ち姿と同じ姿勢＝回転なし）。手は手首→人差し指と小指の付け根の中点、足は足首→つま先。フレームの間は関節位置を直線補間。移動（root）があれば腰の位置を最初のフレームからの差だけ動かす｜JSON の骨の向き（boneDirs）より関節位置の方が情報が多い（肩の線・耳の線など）ため。体の大きさが撮影した人と違っても、向きだけを使うので崩れない。
- 2026-11-26｜サンプルの動き｜手元に JSON がなくても試せるよう、同じ形式（dizz-mocap-v1、30fps、6秒）の動きをプログラムで作った（その場で歩く→右手を振る）｜確認用。
- 2026-11-26｜胴の胸郭の断面の高さ｜胴の「胸」の断面を、胸（乳房）の高さ位置ではなく、アンダーバストと脇のちょうど中間に置く｜胸の高さ位置に連動させると、脇の断面との間が 1.5cm しかない体型で胸の前に折れ目の線が出た（動かしたときに見えた）。
- 2026-11-26｜JSON の開き方｜「JSON を開く」ボタンに加えて、JSON ファイルを画面のどこにドラッグしても開けるようにした。試し用にサンプルの動きを `body-motion/samples/sample_motion_walk_wave.json` として置いた｜Claude アプリの組み込みブラウザではファイルを選ぶ画面が使えないことがあるため（写真分析成形で確認）。
