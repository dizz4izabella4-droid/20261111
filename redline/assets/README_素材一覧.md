# REDLINE フォトリアル素材セット v0.1

画面上部を白いホワイトボード、下部を書類が積まれたデスクとするゲーム向け。
各PNGは独立して配置・拡大縮小できる。`desk/` の9点と `props/` の押しピン4点は透過PNG。

## 利用の区分
- `board/`：ホワイトボード・デスクの背景帯。素材として画像化された室内の一部分のみを使う。
- `evidence/`：小さな証拠写真。基本はホワイトボードに貼る。
- `photo_prints/`：白い印画紙の縁を付けた証拠写真パーツ。ホワイトボード上で使う。
- `maps/`：地図や間取り図。
- `papers/`：メモ・紙面・フォルダ類。
- `desk/`：画面下部に配置する透過小物。
- `props/`：押しピン等。

## 実装上の注意
- 赤い紐の接続線は画像素材を使わずプログラム側で描画。
- 生成画像の日時・文字・地図上の場所は正確性保証がないため、**パズル正解の唯一の手掛かりとして使わない**。必要な情報は別レイヤーで正確に表示する。
- 第1問・第3問・第5問の観察ロジックに使う写真の組合せは、素材を当て込んでから整合性を再検証すること。
- 素材はAI生成のオリジナルのため、既存の写真のライセンス表記義務はないが、商用配布条件は利用先サービスの規約を確認。
