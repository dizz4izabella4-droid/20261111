# ASSUMPTIONS（判断の記録）

書式：日付｜項目｜判断｜理由

- 2026-11-26｜アプリの分離｜動く素体（body-motion）から、動きの部分を「傀儡」として分けた。体はスペアボディの GLB を読み込む（スペアボディのコードは持たない）｜ユーザーの指示。体とのやりとりをファイルにしておけば、どちらも単独で開発できる。
- 2026-11-26｜読み込む体｜骨格つき GLB（スキンメッシュ）。骨の名前でつなぐ（hips, spine, chest, neck, head, upperarm_l, forearm_l, hand_l, thigh_l, shin_l, foot_l と _r、任意で toe_l/toe_r）。足りない骨はその部分を動かさず、画面に表示する。読み込んだときの姿勢（バインドポーズ）を立ち姿とする｜スペアボディ以外の GLB でも、同じ名前の骨があれば動くように。
- 2026-11-26｜動きの当て方｜「モーション」の JSON（dizz-mocap-v1）の 33 点の関節位置から、立ち姿からの回転（ワールド空間）を求め、最終の回転＝その回転×立ち姿の回転として当てる（立ち姿の骨に回転があっても動く）。腰・胸は肩と腰の線と背骨、背骨・首は中間、頭は耳の線、腕・脚・足は親に対していちばん小さい回転で向きを合わせる。腰と胸は体の立ち姿の線を基準にする（立ち姿と同じ姿勢＝回転なし）。手は手首→人差し指と小指の付け根の中点、足は足首→つま先（体のつま先の骨に合わせる）。移動（root）があれば腰を最初のフレームからの差だけ動かす。ねじれ・うなずきは関節位置から決まらないので加えない｜体の大きさが撮影した人と違っても、向きだけを使うので崩れない。
- 2026-11-26｜同梱のサンプル｜`public/samples/` にスペアボディの男性・女性の GLB と、サンプルの動き（dizz-mocap-v1、歩く→右手を振る、6秒）。開いたときは男性の体を読み込む｜ファイルがなくても試せるように。男性はユーザーの指示で実験用の既定。
