# スペアボディ — 引き継ぎメモ（別チャットで再開するときに最初に読む）

最終更新：2026-11-26

## これは何か

スライダーで全身の素体（マネキンのような体）を形づくり、
- **体の設定**（`*.spare.json`）として保存・再読み込みし、
- **骨格つきの体**（`*.glb`）として書き出す

ブラウザアプリ。書き出した GLB は、姉妹アプリ **傀儡（`kugutsu/`）** で読み込んで動かす。

由来：写真分析成形（`photo-tex/`、凍結）の胴・胸のモデル → 動く素体（`body-motion/`、分離前の元）→ 形づくりの部分がここ。

## 座標と骨格

- メートル、+Y 上、+Z 体の前、+X 体の左、床 y = 0（両足の中央が原点）。
- 骨（親子）：`hips` ─ `spine` ─ `chest` ─ `neck` ─ `head`、`chest` ─ `upperarm_l` ─ `forearm_l` ─ `hand_l`（_r も）、`hips` ─ `thigh_l` ─ `shin_l` ─ `foot_l` ─ `toe_l`（_r も。toe は頂点のない端）。
- 立ち姿（バインドポーズ）ではすべての骨の回転なし。脚はまっすぐ、腕は「腕の開き」の角度だけ横に開く。
- 標準では全身を一つの閉曲面に接合。パーツ名は面の分類として残るが、接合する側は同じ頂点・法線・ウェイトを共有する。胴は腰→背骨→胸、肩は胸→上腕、肘は上腕→前腕、股は腰→太もも、膝は太もも→すね、手首・足首・首も近接する骨で滑らかに分ける（最大4本、非負・正規化）。`seamCorrection: 0` は従来の独立した部位と比較するモード。

## ファイル形式

**体の設定**（`*.spare.json`）
```json
{ "format": "spare-body-settings-v1", "name": "spare_body", "preset": "standard", "bodyPreset": "male", "params": { "torsoHeight": 0.67, "...": 0 } }
```
値は内部単位（長さ m、角度 °、指数 0〜100）。キーは `src/model/params.ts` の `GROUPS`。

任意の `softness` フィールドに、`radius`・`hardThickness`・`softThickness`（m）、`smoothing`（0〜10回）、`maxOffset`（m）、`damping`（0〜1、大きいほど早く収束）、`regions`（胸・お腹・腰・腕・脚・頭首・手足の倍率0〜1）を保存する。古い設定ファイルでは柔らかさの初期値を補う。体型プリセットを切り替えても柔らかさは維持する。

**体の GLB**（傀儡が読む）：glTF 2.0、スキンメッシュ 1 つ、上の骨 59 本（ノード名＝骨の名前）、立ち姿で回転なし、逆バインド行列は平行移動のみ。シーンの `extras` に `format: "spare-body-glb-v1"`・`heightMeters`・`params`。Blender 5.3 で骨格・頂点グループつきで読み込めることを確認済み。

2026-11-26追加：独自の float SCALAR 頂点属性 `_SOFTNESS`（0〜1）、`_MAX_OFFSET`（m、柔らかさを掛けた後の実際の移動上限）、`_DAMPING`（0〜1）を出力する。`extras.softness` に `format: "spare-body-softness-v1"`、生成設定と単位・意味を記録。three.js の GLTFLoader では `_softness`・`_max_offset`・`_damping` の小文字名で取得できる。通常の青い見た目は維持し、プレビューの色分け・揺れアニメーションは書き出さない。これらの独自属性は読み込み先で利用する処理が必要（傀儡は未対応）。追加後のGLBはGLTFLoaderで再読み込みして検証済み。Blenderでの独自属性保持は未検証。

接合有効時は `extras.seams` に `format: "spare-body-seams-v1"`・連結成分数・開いた境界の数・接合名を付ける。接合形状・共有頂点・連続ウェイトそのものは通常のglTFメッシュ／スキンに入るので、読み込み側に特別な接合処理は不要。従来の19本の名前・順番を維持し、両手の指40点を末尾に追加する。

## 肩・全身のつなぎ目

- 「胴 → 肩の形」：`shoulderDrop`（m、首の付け根から関節まで）、`shoulderForward`（m、正で前）、`shoulderRoundness`（0〜100）。
- 「つなぎ目」：`seamCorrection`（0〜100、0で従来形状）、`seamWidth`（0〜100、接合範囲）、`jointBlend`（0〜100、骨の重みを切り替える帯幅）。通常のparamsと一緒に保存・読み込みする。古い設定には初期値を補う。
- 胴は既存の格子を残し、肩と首の接合口だけ開く。下腹部から左右の脚は、股の共有アーチで分岐させる。開口の投影弧長から対応する輪を作り、共通インデックスで接続。腕・脚は肘・膝で分断しない連続した断面列にする。頭・手首・足も短い帯で接続する。
- 接合帯だけTaubin型の局所ならしを行い、左右の対応頂点を維持。共有頂点の法線は面積×角度で平均化。境界外の胴・胸の格子を全体リメッシュしない。
- 接合前に開口輪郭の曲がりを検出し、角の強い箇所だけ自動で丸める。変位は最大9mm×補正強度、周囲35mmで滑らかに0へ減衰。修正後の法線を再計算してから接合帯を作るため、元の胴の角をそのまま接合へ持ち込まない。補正はスライダー変更のたびに再生成され、GLBの形状にも含まれる。`seams.roundedVertices` は自動ならしが働いた頂点数。
- 腕が胴に近い場合は断面全体の位置と局所表面を調整して食い込みを避ける。太ももの内側も左右が重なりにくい形にする。
- 毎生成時に頂点・ウェイトの有限性、面積、辺の向き・共有数、開いた境界、連結成分を検査。不正な場合は元の形に戻して画面に理由を表示する。交差は回帰テストで検査（男女・軽量・腕の開き0/18/80°の接合部）。任意の全身自己衝突を保証する検査ではない。
- 「曲げてつながりを確認」は通常の線形スキニングによる確認用の姿勢。挙上0/45/90/135/180°、ねじり±90°、肘・膝120°、股・胴の屈曲はGLBを再読込して接続維持・有限性・面の退化を検証。姿勢は設定・GLBに含めない。
- 参考メモにある `Joint_Smoothing_Engine`、DQS、補助鎖骨、コタンジェント拡散、SDF融合、PSD/RBFはこのリポジトリの既存機能ではなく、今回も実装していない。現在の生成トポロジーに合わせた接合と解析的なウェイト遷移を採用した。

## 柔らかさの調整

- 参考：ユーザー提供 `files.zip` の `softness_bake.html` / `softness_bake.py` と設計書。外部ファイルの実行やライブラリ追加は不要。
- 骨の線分までの最短距離 − 骨の半径を厚みとし、2つの厚み閾値で smoothstep、隣接頂点で平滑化する。
- 部位倍率は既知の体パーツから決める。胴の胸・お腹・腰は高さで滑らかに補間。部位倍率を平滑化の後に掛け、0指定の部位を厳密に固定する。
- 生成された体の左右対称性と、同位置に重複した継ぎ目の頂点を考慮して平滑化する。最短距離・隣接関係・直近の計算結果は形ごとにキャッシュする。
- 「揺れを試す」は静止した体への横方向の減衰応答を表示する見本。衝突・体積保持やモーションへの追従は扱わない。最大8秒、停止・設定変更時に元の形へ戻す。
- 狭いウィンドウでは固定視点の全身が収まるよう表示倍率を調整する。ユーザーによる回転・ズームも可能。

## わかっている問題・次の候補

- 接合後も大きな屈曲・ひねりでは線形スキニング特有の体積減少が起こる。離れた部位同士の衝突（手と太ももなど）も扱っていない。DQS・姿勢に応じた体積補償・衝突処理は今後の改善。
- 肩の半球を浅くした従来形状は補正量0の比較用として保持している。通常は肩の端を取り除き、胴と連続した帯に置き換える。
- 顔・足は仮の箱。手は指付きの連続したメッシュに置き換え済み（補正0時のみ従来の箱）。
- 女性の胴・胸は photo-tex で調整した値。手足・頭はそれに合わせて縮めた（身長約 153cm）。男性はゴツい体型（約 188cm）。
- 作品一覧（`data/works.json`）には未登録、push もまだ（2026-11-26 時点で main 未反映。作業はブランチ `photo-tex`）。

## 2026-11-27：顔の写真・画像と切り取り

- UIは「おまけ：顔に写真・画像を貼る」。ファイル選択、縦3:4の切り取りプレビュー、左右・上下の中心位置、拡大率100〜400、ドラッグ移動、適用、顔の拡大、取り外し。元画像は30MB以下、ブラウザが読める画像を最大辺2048pxのJPEGに縮小し、切り取りを384×512 PNGにする。画像の送信や外部ライブラリの追加はない。
- `model/facePhoto.ts`：切り取り矩形・保存データの検証・頭の正面に置く四角形。`ui/facePhotoPanel.ts`：選択・切り取り操作。Viewerでは既存のheadボーンへ写真の面を付け、姿勢に追従。手拡大と柔らかさ表示では隠す。体型変更時も画像を維持し、頭の寸法に合わせて再配置。
- `.spare.json`の任意の`facePhoto`に`source`（縮小した元画像）、`texture`（適用済みPNG）、`crop:{x,y,zoom}`を保存。画像なしの旧設定も読める。未適用の編集は保存対象外。

- 現在の頭は仮の箱なので、正面への平面的な画像貼り付け。顔の立体化・表情生成・カメラ撮影機能はない。
