プロシージャルモデリング 形状自動生成アプリ 説明書
====================================================
対象ファイル: procedural.html（1ファイル完結。3D表示ライブラリの読み込みにネット接続が必要）
作成日: 2026-11-27 時点の仕様。テクスチャは扱わない（別アプリで貼る前提のポリゴン素体づくりに特化）。

【1. 何ができるか】
  1) 数値・規則による3D形状の生成（テンプレート52種）
  2) パーツの自動配置・反復（配列・放射・グリッド・散布・段積み・ミラー）
  3) パラメータ変更による形状の再構築（スライダーを動かすと即座に作り直す。シード固定で再現可能）
  4) テンプレートの選択による生成、廃墟化（破損）、植生（蔓・草・苔）
  5) 生成した形をOBJ形式で書き出し（UV・法線つき、色や材質は含まない）

【2. 画面の見かた】
  PC: 左=テンプレート一覧 / 中央=3D表示 / 右=設定パネル / 下=統計バー
  スマホ（幅760px以下）: 上=テンプレート（横スクロール）、その下に3D表示（画面上部に固定）、下に設定パネル
  3D表示の操作: ドラッグ=回転 / ホイールまたはピンチ=拡大縮小
  統計バー: パーツ数、三角形数、生成時間(ms)、概寸（幅×高さ×奥行の目安）、警告
  キー操作: Ctrl+Z / ⌘+Z で戻す、Shift を足すと進む

【3. 右パネルの項目（上から）】
  ■ テンプレート名の見出しと、そのテンプレート固有のスライダー（5.に一覧）
  ■ 全テンプレート共通のスライダー
    - シード（1〜999）: 乱数の種。同じ値なら同じ形になる。変えると別の形・別の壊れ方
    - 色相シフト（-0.5〜0.5）: 全体の色味を一括でずらす
    - 全体ねじり（-60〜60 度/高さ）: 高い位置ほどY軸まわりにねじる
    - 全体先細り（0〜0.95）: 高い位置ほど細くする
    - 全体ゆらぎ（0〜1.5）: パーツ位置を乱数でずらす
    - 放射コピー数（1〜12）: Y軸まわりに回転コピー
    - 全体の大きさ（0.3〜2）: 全体の倍率
  ■ ボタン列
    - 乱数化: すべての数値スライダーを範囲内でランダムにし、シードも変える
    - シード+1: シードだけ進める（バリエーション確認用）
    - ワイヤー: 線画表示の切り替え
    - 初期値: テンプレートの初期値に戻す
    - 戻す／進む: 操作履歴（最大60件）
    - 自動回転: カメラの自動回転（ドラッグ中は止まる）
  ■ モディファイア（上から順に適用）… 6.に詳細
  ■ 表示
    - ローポリ／滑らか: 面のカクカクを残すか、なめらかに見せるか
    - 素体(グレー): 全体を単色グレーにして形だけを見る
    - 影: 床への影（既定オン）
    - グリッド: 床の格子の表示
    - 光: 昼→夕→夜の切り替え
  ■ 断面エディタ（「回転体(断面編集)」選択時のみ表示）… 7.に詳細
  ■ L-systemルール欄（「L-system(自由記述)」選択時のみ表示）… 8.に詳細
  ■ ギャラリー: 「現在を保存」で最大12件。ボタンで呼び出し。ブラウザの localStorage に保存
  ■ 設定JSON: 「現在値を表示」で現在の設定を文字列で表示。貼り付けて「読み込む」で復元
    （テンプレート名・シード・パラメータ・L-systemルール・断面・モディファイアを含む）
  ■ OBJ書き出し / 結合ON・OFF: 9.に詳細

【4. 数値の単位】
  長さの単位は仮に「m」として設計（床グリッド1マス=1）。概寸表示も同じ単位。

【6. モディファイア（加工の積み重ね）】
  使い方: 種類を選んで「追加」。上から順に適用される。↑↓で順番入れ替え、✕で削除。
  どのテンプレートにも後付けできる。種類を変えても設定は保持される。
  適用順は「テンプレート → モディファイア → 全体スライダー（ねじり・先細りなど）」。
  ◆ 配列: 指定間隔で直線状にコピー
      項目: 個数(2〜12)、X/Y/Z間隔(-6〜6)
  ◆ 放射: Y軸まわりに円形にコピー
      項目: 個数(2〜16)、半径(0〜8)
  ◆ 植生(蔓・草・苔): 既存パーツに蔓を這わせ、地面近くに草、上面に苔を置く
      項目: 蔓の本数(0〜300)、蔓の長さ(1〜12)、草の量(0〜800)、苔(0〜500)
  ◆ 破損(廃墟化): ノイズで欠けを塊にし、縁を傾け、上から崩し、瓦礫を落とし、風化色にする
      項目: 破損率(0〜1)、欠けの大きさ(1〜8)、崩落(0〜1)、傾き(0〜30度)、瓦礫数(0〜200)、崩れる側(0全体 1:+X 2:-X 3:+Z 4:-Z)
  ◆ 段積み: 縮小・ねじりしながら上に積む
      項目: 段数(2〜20)、段の高さ(0.2〜6)、縮小率(0.6〜1.2)、ねじり(-45〜45度)
  ◆ グリッド: XZ平面に格子状にコピー
      項目: X個数・Z個数(1〜12)、X間隔・Z間隔(0.5〜8)
  ◆ ミラー: 軸で鏡写しにコピー
      項目: 軸(1:X 2:Y 3:Z)
  ◆ 散布: 範囲内にランダムな位置・向き・大きさでコピー
      項目: 個数(2〜60)、範囲(1〜15)、大きさのばらつき(0〜0.8)

  破損(廃墟化)の仕組み（単調にしないための工夫）
   - 滑らかなノイズで破損を決めるので、欠けがばらばらでなく塊になる
   - 欠けの縁のパーツは傾き、少し沈む（きれいな切り口にならない）
   - 壁の上端がノイズでギザギザに下がる（崩落）
   - 破損が強い部分ほど暗く・くすんだ色になる
   - 抜けたパーツが小さくなって足元に散らばる（瓦礫）。大きな部材は縮めて落とす
   - 「崩れる側」で、片側だけ強く崩せる
   - 同じテンプレートでも、シードを変えると別の壊れ方になる。破損を2回重ねるとさらに崩れる

【7. 断面エディタ（回転体(断面編集)）】
  - 縦=高さ、横=半径。点の近くを押してドラッグすると形が変わる（点の上下の順序は入れ替わらない）
  - 点を追加: いちばん間の空いた2点の中間に追加 / 選択点を削除: 最低3点は残る
  - プリセット: 花瓶、ワイングラス、コマ、ボウル、ひょうたん、細長い壺
  - 高さ・太さ倍率・周方向分割は通常のスライダーで調整

【8. L-system(自由記述) のルール文】
  書式: 1行に1つ。 axiom=A で出発文字列。 A=置換先 の形で規則。 先頭が # の行は無視。
  確率: A=0.7:F[+A] のように先頭に確率を書く。同じ記号を複数行書くと確率で選ばれる。確率を省くと残りを均等配分。
  記号: F=前進して枝を描く / + - = 左右に回す / & ^ = 上下に回す / r = ねじり(黄金角)
        ! = 枝を短く細くする / [ ] = 枝分かれの開始・終了 / A = 葉(球) / B = 花(球) / L = 平らな葉
        ' = 色相をずらす / < = 枝を太く / > = 枝を細く
  プリセット: 樹、花の樹、虹の螺旋
  調整項目: 世代数、角度、縮小率、花の大きさ、葉の大きさ、太さの減り、幹の太さ、幹・葉・花の色相
  注意: 世代数が大きいと急に重くなる（文字列は80万字で展開を打ち切る）

【9. OBJ書き出し】
  - 「OBJ書き出し」で procedural.obj を保存。UV・法線を含む。色・材質・テクスチャは含まない
  - 結合:OFF = パーツごとに別オブジェクト名（box_1、cyl_2 など）。結合:ON = すべてを procedural という1つのオブジェクトにまとめる
  - ミラーで裏返ったパーツは、面の向きを補正して書き出す
  - 頂点の溶接や、重なった内側の面の除去はしない
  - 公開ページ(claude.ai上)では保存が効かないことがある。その場合はHTMLファイルをブラウザで直接開いて使う

【10. 上限と動作】
  - パーツ数の上限は25万個。超えると生成を打ち切り、統計バーに警告を出す
  - 変化がないときは描画しない（電池の節約）。スライダー操作は1フレームに1回まで再生成
  - 色テーマ（ライト／ダーク）は端末の設定に追従する

【11. 既知の制約】
  - 各部品はパーツの重ね合わせで、1枚につながったメッシュではない（めり込みや内側の面が残る）
  - 屋根は2枚の板のみ（妻側なし）。蔓は壁の形によってめり込み・浮きが出ることがある
  - 概寸はパーツの中心位置から求めた目安で、実際よりやや小さく出る
  - 「戻す」「ギャラリー」「JSON」に、表示設定（影・光・素体など）は含まれない
  - メンガーのスポンジ〜ドーム(タイル)の8種は、この説明書では名前と項目からの簡易説明のみ

【12. おすすめの使い方】
  - 廃墟の建物: 破損率0.3・崩落0.45あたりから始め、シードを変えて好みを探す。片側だけ崩すなら「崩れる側」を指定
  - 街区: 廃墟の街区で全体を作り、緑の量で雰囲気を調整
  - 部品の組み合わせ: 柱＋配列で列柱、レンガ壁＋放射で円形の塀、樹木＋散布で林
  - 別アプリでテクスチャを貼る素体: 素体(グレー)で形を確認 → 結合ON/OFFを選んでOBJ書き出し
