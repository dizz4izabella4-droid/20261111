# BRAIN 試作 v4（v3.1 からの最小改修）
起動: このフォルダで `python3 -m http.server 8000` → http://localhost:8000/
本番トップは未変更。専用パス（例: brain-qa/）に置いて確認すること。

## v3.1 からの変更（これだけ）
- 月を背景画像から除去（空パッチで置換）し、`assets/moon.webp` の固定スプライトに分離。背景が流れても月は増えない・動かない。
- 背景を `forest_strip.webp`（1652×724）に差し替え。左右端を520pxクロスフェードして、継ぎ目のない横ループにした（鏡像は対称の木が目立つため不採用）。
- 粗い前景マット（二重像の原因）を撤去。
- 開いた窓の内側にあった横縞を撤去。
- リール・スナップ・開閉・キーボード操作・遷移ロジックは v3.1 のまま。

## 確認済み（実ブラウザ Chromium、1440×900／390×844）
- コンソールエラーなし、画像の読込失敗なし。
- ドラッグ→スナップ、窓の開閉、継ぎ目付近のスクリーンショットで継ぎ目が見えないこと。
