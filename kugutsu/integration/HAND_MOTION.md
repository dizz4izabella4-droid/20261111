# 指モーションとスペアボディの接続

## 操作

1. 指付きの体（GLB）を開きます。指のない従来の体も、全身モーションには引き続き使えます。
2. 「指の動き（JSON）を開く」から、アプリ「指モーション」で保存したJSONを読み込みます。左右はJSONの`handedness`で自動判定し、それぞれ1本ずつ保持します。JSONのドラッグでも読み込めます。
3. 全身のJSONがあれば重ねて再生します。全身を読み込まなければ、立ち姿の体で指だけを再生できます。
4. 左右の「開始（秒）」で時間をずらせます。正の値は遅らせ、負の値は先へ進めます。開始前は最初の指の姿勢、終端後は最後の指の姿勢を保持します。「くり返す」が有効な場合は指クリップも繰り返します。
5. 既定では手首を全身モーションに任せます。「手首の向きも反映」を有効にすると指モーション側の手全体の向きも重ねます。
6. 「体＋モーションを保存（GLB）」で、全身・左右の指・有効なら柔らかさも同じアニメーションに焼き込みます。Three.js側の読み込みコードは変更不要です。

全身のJSONがある場合は全身の長さで再生・保存します。指だけの場合は開始時間を含む最長の指クリップに合わせます。保存時のサンプルレートは全身と指のうち最も高いfpsを使います。

## 入力データ

形式は`hand-mocap-v1`。`handedness`は`Left`または`Right`。`frames`は1フレーム63数値（21点×XYZ）、`joints`・`parents`・`restOffsets`を使います。単位はメートル、Y上、手首原点。右手用のJSONは出力済みの右手として扱い、二重には反転しません。

既存キャラクターと初期姿勢・骨軸が異なるため、入力の`localRotations`をそのまま骨へ代入しません。関節方向を手のひらの座標系へ移し、読み込んだ体の初期姿勢に合わせて骨を回転します。体の寸法や指の長さは変更しません。

## 指付きGLBの骨名

手首は`hand_l`／`hand_r`を使います。`wrist_l`／`wrist_r`のみの体も手首として認識します。アプリ「指モーション」の`wrist_l`／`wrist_r`はそれぞれに対応します。

各指は次の名前に`_l`または`_r`を付けます。

```text
thumb_cmc → thumb_mcp → thumb_ip → thumb_tip
index_mcp → index_pip → index_dip → index_tip
middle_mcp → middle_pip → middle_dip → middle_tip
ring_mcp → ring_pip → ring_dip → ring_tip
pinky_mcp → pinky_pip → pinky_dip → pinky_tip
```

各列の先頭は手首の子、以降は左から右の親子関係です。指先のtipは方向を決める端点で、親に追従します。頂点は対応する指の骨へスキンされている必要があります。骨だけ増やしても、手のメッシュにウェイトがなければ見た目は曲がりません。

骨がない・不足する場合は画面に表示し、指データを保持します。全身や左右いずれかの指が欠けた出力を避けるため、対応する体に交換するか、その手の指データを外すまで保存を無効にします。スペアボディ本体の改修ファイルを傀儡から変更する処理はありません。

## 開発と検証

- `_src/src/motion/hand.ts`：JSONの検証、補間、手のひらを基準にした指の適用。
- `_src/src/motion/timeline.ts`：全身と指の共通時間。
- `_src/tests/hand.test.ts`：左右、異なる初期骨軸、手首、カメラ向きの除去、時間差、旧モデル、GLB再生の検証。
- `_src/scripts/hand-samples.mjs`：Mac上の`hand_mocap_tool.html`から元の出力処理を使ってテスト用JSONを生成。別の場所にある場合はHTMLのパスを引数に渡せます。
- `_src/scripts/check-export.mjs`：実画面の左右読み込み、体交換、時間差、手首設定、ダウンロード、別Three.jsシーンでの指再生を確認。テスト用の指骨付きGLBは接続仕様の検証用であり、スペアボディの完成モデルではありません。
