# 仕立て屋

素体に合わせて衣装を作る道具。部品を選び、寸法と色をつまみで変えると素体に着せられ、傀儡で使える GLB に書き出せる。
`index.html` を開くだけで動く（外部への通信なし）。女性素体向けに調整している。

## できること
- 部品：上衣（常に着る）・袖（広がる／細い／なし）・スカート・前掛け・帯と垂れ紐・マント・フード・縁飾り
- 見本の型：旅の巫女（`outfit-sample` の衣装が元）・町娘・魔術師・神殿の従者
- 型の保存と読み込み（JSON）。ブラウザにも自動保存
- 下書き（数秒）と仕上げ（10〜20 秒）の 2 段階。GLB 書き出しは仕上げで計算してから保存
- 素体 GLB の差し替え（スペアボディの書き出し）

## 作り直し方
`_src/` を編集して、esbuild と three@0.187.0 を入れたフォルダを指定してまとめる。

    npm install --prefix /tmp/deps esbuild three@0.187.0
    DEPS=/tmp/deps node _src/build.mjs

| ファイル | 中身 |
|---|---|
| `_src/garments.js` | 部品ごとの形の作り方（距離場と布の計算） |
| `_src/mesh.js` | 色・縁・骨の重み・GLB 書き出し |
| `_src/design.js` | 型の項目、範囲、見本、配色 |
| `_src/body.js` | 素体の読み込みと寸法取り |
| `_src/app.js` / `worker.js` | 画面と裏の計算 |

新しい部品を足すときは、`design.js` に項目、`garments.js` の `plan` と `makeRunner` に工程、`mesh.js` に縁と重み、`app.js` に設定画面を足す。

## まだできないこと
- 実行時の布の揺れ（`_MAX_DISTANCE` は書き出し済みだが、使う側が未対応）。脚や肘を大きく曲げると素体が服を突き抜ける
- ゲーム向けの面数削減（仕上げは服だけで約 2.1〜3.6 万三角形、下書きは約 1.1〜2.1 万）
- 男性素体向けの調整
- ズボン、靴、帽子などの部品
