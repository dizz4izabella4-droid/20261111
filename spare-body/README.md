# スペアボディ（spare-body）

スライダーで全身の素体を形づくり、体の設定（`.spare.json`）の保存・再読み込みと、骨格つきの体（`.glb`）の書き出しができるブラウザアプリ。書き出した体はアプリ「傀儡」（[`../kugutsu/`](../kugutsu/)）で動かせる。

引き継ぎ・ファイル形式・起動方法は [HANDOFF.md](HANDOFF.md)、判断の記録は [ASSUMPTIONS.md](ASSUMPTIONS.md)。

「柔らかさ」タブでは、骨からの距離をもとにした動きやすさを色で確認し、部位ごとの強さ・移動上限・収まり方を調整できる。「揺れを試す」はローカルの見本。設定は `.spare.json` に、頂点ごとの柔らかさ・移動上限・減衰は GLB に保存する。傀儡での揺れ再生には、傀儡側の対応が必要。

肩の下がり・前後・丸みを調整できる。標準では肩・股関節・肘・膝・首・手首・足首など14か所を共通の頂点でつなぎ、形・法線・骨の重みを連続化する。「つなぎ目」で補正量・範囲・曲がりの広さを調整し、補正量0で元の分割形状と比較できる。「曲げてつながりを確認」から挙上・屈曲・ひねりを試せる。姿勢は確認用で、GLBは立ち姿の連続したメッシュとして書き出す。


「体の形 → 腕」で、体につながる5本指を成形できる。各指の長さ・太さ、指先の細さ、関節のふくらみ、指の開きを調整し、拡大表示と曲げ確認ができる。骨格は全身59点で、指モーションの手首＋20点に対応する名前・親子関係と対応表をGLBに含める。手に柔らかさの設定は不要。

既に作成したJSON再生・手単体GLB出力は「手・指の確認 → 連携の補助機能」に保持した。指モーション本体は変更していない。合成データの変換はテスト済みで、実収録データとの連携は未確認。

基本表示は軽く握った手。「手を開く」で成形を確認し、「基本の握りに戻す」で戻せる。GLBは指モーション連携用の開いた基準姿勢で出力する。


「おまけ：顔に写真・画像を貼る」で撮影済みの写真・画像ファイルを選び、ドラッグまたは位置・拡大率の調整で切り取れる。「切り取って顔に貼る」で仮の頭の正面に貼り、「顔を拡大」で確認。「顔画像を外す」で取り除ける。処理は端末内で行う。体の設定には画像と切り取り位置を、全身GLBには切り取ったPNGを含める。写真から立体の顔を生成する機能ではない。

単体HTML版は `releases/spare-body.html`。ブラウザで直接開けるようJavaScriptとCSSを内包する。更新時は `_src` で `npm run build` → `npm run export:html`。同じ入力の再出力は省略する。
