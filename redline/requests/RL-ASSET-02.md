# 依頼シート：REDLINE 追加素材（RL-ASSET-02）

作成日：2026-11-18 ／ 依頼元：ユーザー（企画兼監督）／ 依頼先：ChatGPT（画像生成）
用途：REDLINE の試遊品（STAGE 03・05）で、いまコード描きのスケッチで代用している写真を、フォトリアルな写真に差し替える。

## 共通ルール
- フォトリアルな屋外の写真風。イラスト風にしない。暗めの夜景〜夕景、既存の素材（石造アーチ、鉄橋、時計塔、路面電車の線路）と同じ雰囲気。
- 横長（約16:9）、**幅1024px以上**。1枚に1つの被写体を大きく、はっきり。
- **画像内に文字・数字・看板の文字・時計・日時を入れない。**
- 下の「写してはいけないもの」は、画面の端や遠景にも一切写さない。パズルの解答が変わってしまうため。
- 形式PNG。ファイル名 `redline_<ステージ>_<ID>.png`（例：`redline_s03_B.png`）。1枚ずつ作る。
- 納品時に、依頼ID、ファイル名、寸法、作成アカウント、権利・利用条件、守れなかった点を正直に書く。
